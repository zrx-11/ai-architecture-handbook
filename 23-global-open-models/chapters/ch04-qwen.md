# 第 4 章 Qwen 家族：从 0.5B 到 2.4T-A95B 的缩放路线

> 难度：中级 · 建议 70 分钟 · 前置：第 3 章
> 学习目标：能列出 Qwen 1→3.8 的代际主线；能区分 Qwen 的 dense、MoE、混合线性注意力三条子路线；能读 Qwen3.5/3.6/3.8 的 config 并算 KV cache。

## 一句话核心

Qwen 是开放模型里少见的“全尺寸、全架构、全模态”家族：小到 0.8B 端侧 dense，大到 2.4T 总参数 / 95B 激活的 MoE，中间还有 397B-A17B、122B-A10B、35B-A3B 和 27B dense；同时做视觉、音频、OCR 和混合线性注意力。它不是一个模型，而是一棵产品树。

## 4.2 三条子路线

### A. 小尺寸 dense

Qwen3.5-0.8B/2B/4B/9B、Qwen3.6-27B、Qwen3.8-27B 都是 dense。它们适合端侧、单卡微调、教学。结构上和 Llama 类似：RMSNorm、SwiGLU、RoPE、GQA。

### B. 大尺寸 MoE

Qwen3.5-35B-A3B/122B-A10B/397B-A17B、Qwen3.6-35B-A3B、Qwen3.8-2.4T-A95B 都是 MoE。共同特征：

- 专家数多：256 或 512；
- 每 token 激活 8 或 10 个；
- 专家内部宽度窄：512–2048，而不是 dense 的 14336；
- KV 头很少：2 或 4；
- 上下文 262,144。

这不是“把 dense FFN 简单复制 256 份”。专家变多、每个变窄，路由更细；总参数涨，激活参数涨得慢。

### C. 混合线性注意力

Qwen3-Next-80B-A3B 是 Qwen 的混合路线：48 层、2048 hidden、16 Q 头、2 KV 头、512 专家、top-10、262K 上下文。它把部分注意力层换成 Gated DeltaNet（线性注意力），保留少量全注意力层。Qwen3.8-Flash-Next 的 `model_type` 是 `qwen4_exp`，说明 Qwen 还在试验下一代骨架；本册按 config 讲事实，不把试验代号当已定论文。

## 4.4 为什么 Qwen 的 MoE 这么“碎”

看 Qwen3.8-2.4T-A95B：512 个专家，每个专家中间宽度只有 2048；Qwen3.5-397B-A17B：512 个专家，宽度 1024。对比 Llama 4 Scout：16 个专家，专家宽度 8192。

两种设计哲学：

| 设计 | 专家数 | 专家宽度 | 路由 | 适合什么 |
|---|---|---|---|---|
| 宽专家、少专家 | 8–16 | 8192–14336 | top-1/2 | 通信少、单机友好 |
| 窄专家、多专家 | 256–512 | 512–2048 | top-8/10 | 容量大、细粒度路由、需要专家并行 |
| 折中 | 64–128 | 2048–4096 | top-4/8 | 多机但通信可控 |

专家越碎，总参数越大，但每个 token 只读一小撮专家；显存要装全部专家，专家并行（EP）通信量也更大。**Qwen 的大模型不是为单卡设计的。**

## 4.5 手算：Qwen3.8-27B 的 KV cache

Qwen3.8-27B：$L=64$，$H_{kv}=4$，$d_{head}=256$，FP16 $b=2$。

$$
2\times64\times4\times256\times2
=262{,}144\ \text{bytes/token}
=0.25\ \text{MiB/token}
$$

262,144 token：

$$
262{,}144\times262{,}144
=68{,}719{,}476{,}736\ \text{bytes}
\approx64\ \text{GiB}
$$

单序列 262K 就要 64 GiB KV。Qwen3.8-2.4T-A95B 更狠：

$$
2\times92\times4\times256\times2
=376{,}832\ \text{bytes/token}
\approx0.359\ \text{MiB/token}
$$

262K 约 92 GiB。**长上下文模型的第一道门槛不是权重，是 KV。**

## 4.6 Qwen 的取舍

| 设计 | 得到什么 | 付出什么 |
|---|---|---|
| 全尺寸覆盖 | 从端侧到集群都有选择 | 同名家族差异大，容易选错 |
| 窄专家 + top-10 | 总容量大、激活低 | 显存、EP 通信、路由训练难 |
| 2–4 KV 头 | KV cache 小 | 头太少可能损失表达；要配合 head_dim |
| 262K 上下文 | 长文档/代码库 | KV 显存、注意力计算、位置外推 |
| 多模态 | 图文/视频/音频 | 视觉 token 预算、连接器训练、数据配比 |

## 4.7 常见误解

- **“Qwen3.8-2.4T 是 2.4T 激活。”** 错，95B 激活；2.4T 是总参数。
- **“Qwen3.5-397B-A17B 和 3.8-2.4T 是同一档。”** 不是，397B/17B 与 2.4T/95B 差一个数量级。
- **“Qwen3.8-27B 是纯文本。”** 它的整体架构是 `Qwen3_5ForConditionalGeneration`，带视觉塔；文本 config 只是其中一部分。
- **“262K 就是能处理 262K。”** 还要看训练长度、RoPE 缩放、KV 显存和注意力实现。

## 4.8 自测

1. Qwen3.5/3.6/3.8 的三条子路线各是什么？
2. Qwen3.5-397B-A17B 的专家数、top-k、专家宽度是多少？
3. Qwen3.8-2.4T-A95B 的激活参数占比约多少？
4. Qwen3.8-27B 在 128K 上下文下单序列 KV 约多少 GiB？
5. 为什么 Qwen 的大 MoE 不适合单卡部署？

> 参考答案：1）小 dense、大 MoE、混合线性注意力；2）512 专家，top-10，宽度 1024；3）95/2400≈3.96%；4）0.25 MiB×131072≈32 GiB；5）总参数 2.4T，权重和全部专家要装进显存，需要多卡/EP。

## 4.9 复习锚点

- Qwen 代际：1 → 1.5 → 2 → 2.5 → 3 → 3-Next → 3.5 → 3.6 → 3.8。
- 三种子路线：dense、MoE、混合线性。
- 大 MoE 特征：256/512 专家、top-8/10、窄专家、2/4 KV 头、262K。
