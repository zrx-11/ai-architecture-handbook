# 术语表

- **Transformer** — 由自注意力、FFN、残差和归一化堆叠成的序列模型骨架（ch02）
- **decoder-only** — 只用因果解码器、按下一个 token 预测训练的架构（ch02）
- **encoder-decoder** — 编码器双向读输入、解码器自回归生成的架构（ch02）
- **注意力** — 让每个 token 根据相关性聚合其他 token 信息的机制（ch02）
- **自注意力** — Q/K/V 都来自同一序列的注意力（ch02）
- **因果掩码** — 禁止 token 看到未来位置的掩码（ch02）
- **MHA** — 每个 Q 头有独立 K/V 的多头注意力（ch13）
- **MQA** — 所有 Q 头共享 1 组 K/V 的多查询注意力（ch13）
- **GQA** — Q 头分组共享 K/V 的分组查询注意力（ch13）
- **MLA** — 把 K/V 压成低秩潜向量再投影的多头潜在注意力（ch13）
- **KV cache** — 推理时缓存的 Key/Value，避免每步重算历史（ch13）
- **RoPE** — 用旋转位置编码让注意力只看相对位置的方案（ch13）
- **YaRN** — 通过改旋转频率/温度把上下文外推的方法（ch13）
- **ALiBi** — 用距离线性偏置代替位置编码的方案（ch08）
- **sliding window** — 每个 token 只看最近 W 个 token 的注意力（ch05）
- **局部/全局注意力** — 多数层看局部窗口、少数层看全序列的交替设计（ch06）
- **RMSNorm** — 只按均方根归一化、不减均值的归一化（ch03）
- **LayerNorm** — 减均值、除标准差再仿射的归一化（ch03）
- **QK-Norm** — 注意力前对 Q/K 做归一化，稳定大 head_dim 训练（ch06）
- **SwiGLU** — 用 Swish 门控的两个线性投影组成的 FFN（ch03）
- **FFN** — Transformer 层里的前馈网络（ch02）
- **MoE** — 把 FFN 拆成多个专家、每 token 只激活 top-k 的架构（ch11）
- **router** — 给每个 token 选择专家并输出权重的门控网络（ch11）
- **top-k** — 每个 token 只激活的专家数量（ch11）
- **expert** — MoE 中独立的一套 FFN 参数（ch11）
- **shared expert** — 所有 token 都经过的通用专家（ch11）
- **total params** — 模型全部权重，决定显存（ch11）
- **active params** — 每 token 实际参与计算的权重，决定算力（ch11）
- **expert parallelism** — 把不同专家放到不同设备上的并行方式（ch11）
- **load balancing** — 让 token 均匀分配到专家的训练约束（ch11）
- **dense** — 每个 token 都走同一套 FFN 的模型（ch11）
- **sparse attention** — 每 token 只和部分历史做注意力的机制（ch13）
- **DSA** — 用索引器选 top-k 历史 token 的稀疏注意力（ch13）
- **linear attention** — 用核函数/递归把注意力降到 O(n) 的方案（ch10）
- **SSM** — 用固定状态递推建模序列的状态空间模型（ch10）
- **Mamba** — 带选择性状态的空间状态模型（ch10）
- **RWKV** — RNN 化 Transformer，time-mix + channel-mix（ch10）
- **hybrid architecture** — 线性/SSM 层与全注意力层混合的架构（ch10）
- **Jamba** — Transformer + Mamba 的混合模型（ch10）
- **Griffin** — RG-LRU + 局部注意力的混合模型（ch10）
- **xLSTM** — 指数门控 + 矩阵记忆的 LSTM 变体（ch10）
- **multimodal** — 同时处理文本、图像、音频等模态的模型（ch12）
- **ViT** — 把图像切 patch 后用 Transformer 编码的视觉模型（ch12）
- **patch** — 图像切分后的固定大小块（ch12）
- **connector** — 把视觉/音频特征投到语言模型维度的模块（ch12）
- **resampler** — 用固定查询把变长视觉特征压成固定 token 的模块（ch12）
- **early fusion** — 在较早层把多模态 token 拼在一起的融合（ch12）
- **late fusion** — 只把视觉特征当外挂、在输入端拼接的融合（ch12）
- **any-to-any** — 文本/图像/音频等任意模态到任意模态的模型（ch12）
- **image token** — 图像 patch 经编码器/连接器后得到的 token（ch12）
- **tokenizer** — 把文本切成 token 的组件（ch15）
- **vocab** — tokenizer 的词表大小（ch15）
- **embedding** — 把 token id 映射成向量的矩阵（ch15）
- **logits** — 模型输出头得到的未归一化分数（ch15）
- **softmax** — 把 logits 变成概率分布的归一化（ch15）
- **context length** — 模型能处理的最大 token 数（ch13）
- **prefill** — 推理时一次性处理输入前缀的阶段（ch13）
- **decode** — 推理时逐 token 生成的阶段（ch13）
- **quantization** — 把权重/激活降到低精度以省显存（ch14）
- **FP8** — 8 位浮点量化格式（ch14）
- **INT4** — 4 位整数量化格式（ch14）
- **license** — 决定能否商用/修改/再分发的法律条款（ch14）
- **Apache 2.0** — 允许商用、修改、再分发的宽松许可证（ch14）
- **MIT** — 比 Apache 更短更宽松的许可证（ch14）
- **Llama Community** — Llama 系列的自定义社区许可证（ch14）
- **Gemma Terms** — Gemma 系列的自定义使用条款（ch14）
- **CC-BY-NC** — 禁止商用的 Creative Commons 许可证（ch14）
- **open weights** — 权重可下载，但不等于代码/数据/商用权利全开放（ch01）
- **benchmark contamination** — 评测题出现在训练数据里导致分数虚高（ch14）
- **model card** — 模型卡：许可证、数据、评测、限制的说明页（ch14）
