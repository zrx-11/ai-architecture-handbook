# SVM 从零推导（深潜专题）

来源：`zrx-11/SVM` 仓库，原样合并，保留其自包含 HTML、内联 KaTeX 与交互式推导。

## 这套课有什么

16 个部分：课程概览、初中数学基础、最大间隔直觉、硬间隔优化模型、硬间隔对偶、KKT 与参数恢复、手算示例、软间隔与 hinge 损失、软间隔对偶、核技巧、常用核函数、核 SVM 预测、scikit-learn 代码与调参、交叉验证与评价、统计学习进阶理论、知识图谱。

原课标注基于杭州电子科技大学王春雪老师《机器学习》课程课件改写，覆盖从硬间隔到核技巧的完整推导链。

## 怎么用

直接打开 `index.html`。每一步推导可展开；代码实验部分需要本地 Python 与 scikit-learn，页面内只给代码与调参说明。

## 在整套学习系统里的位置

- 先读 `04-machine-learning` 第 2 章（模型评估）和第 6 章（支持向量机），知道 SVM 在机器学习里的位置。
- 再进这套深潜课，把对偶问题、KKT、软间隔、核技巧完整推一遍。
- 如果只想先建立直觉，读第 1–2 节即可；要做代码实验，直接跳第 11–12 节。
