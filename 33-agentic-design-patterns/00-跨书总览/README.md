# 总览：这本书怎么学，两个深推页在哪

## 先说结论

这不是一本"讲 21 个技巧"的书。它讲的是：**每个模式解决哪一类具体故障，以及它在什么条件下会失效**。学完的标志不是记住名字，而是拿到一个需求能判断"该不该上这个模式"。

## 两个深推页（从零推导）

这两页把书中两个最容易"看懂了但推不出来"的主题，从初中数学推到工程判断：

| 页面 | 起点 | 终点 |
|---|---|---|
| [从零推导 · RAG](../从零推导-RAG.html) | 分数运算、勾股定理 | 自己推出余弦相似度公式、判断 RAG 四环哪一环出了错 |
| [从零推导 · 反思](../从零推导-反思.html) | if/else、概率含义 | 自己设计带外部判据与出口条件的反思回路 |

阅读时机：RAG 那页放在第 14 章之前读；反思那页放在第 4 章之前读。两页都内联了 KaTeX 与字体，可离线打开。

## 推荐顺序（按依赖，不按书序）

1. 第 0 章 → 建立"智能体 = 认知引擎 + 架构"的框架
2. 第 1 章 → 学会把任务拆成可验证的片段
3. 第 2、3 章 → 选路与并发
4. 第 5 章 → 给模型一双手（工具是判据的来源）
5. 第 4 章 → 反思（此时才有测试可当判据）
6. 第 6 章 → 规划
7. 第 14 章 → RAG（先读深推页）
8. 第 8 章 → 记忆
9. 第 11、12、13 章 → 目标、异常、人机边界（治理三件套）
10. 第 20、16 章 → 调度与成本
11. 第 7、10、15 章 → 协作与协议
12. 第 9、17 章 → 学习与推理
13. 第 18、19 章 → 护栏与评估
14. 第 21、22 章 → 探索与收束

## 学完能做什么

- 拿到需求先定自主等级（Level 0~3），再选模式，而不是先选框架；
- 为每条链写出输出契约与校验点；
- 算清单次调用成本与并行收益；
- 说出每个模式的失效条件，并给出兜底方案；
- 设计一套可验证的评估（轨迹 + 指标 + 趋势）。
