# 点化学习系统 · 交付说明

本包是一套可直接学习的系统化知识库手册：统一入口 `index.html`，每本书另有独立学习伴侣。

**交付模式**：`full`（最终产物 + 中间产物）

## 一、书目

| 目录 | 书 | 章节 | 概念 | 测验 | 抽认卡 | 术语 |
|---|---|---|---|---|---|---|
| 01-智能体设计模式 | 智能体设计模式：智能系统构建实战指南 | 26 | 11 | 58 | 52 | 77 |

## 二、目录说明

| 路径 | 说明 |
|---|---|

## 三、使用方法

1. 双击 `index.html`：顶部切换书籍与总览，左侧按学习路径/章节/概念/测验/抽认卡/术语/模式/速查浏览。
2. 学习进度、测验记录、卡片复习状态保存在浏览器本地（localStorage）。
3. 单书伴侣：各书目录下的 `*学习伴侣.html` 可单独打开。

## 四、部署 GitHub Pages

```bash
# 把包内全部文件放到仓库根目录后
git add -A && git commit -m "点化学习系统" && git push origin main
# Settings → Pages → Deploy from a branch → main → / (root) → Save
```

访问 `https://<用户名>.github.io/<仓库名>/` 即进入总学习手册。

## 五、验证结论

**总入口**：`verify_handbook.py` 17 项全过（17/17 PASS），覆盖首页与书卡、总览页、首章与末章渲染、58 道测验作答与解析、抽认卡翻转与"认识"计数、术语过滤、全局搜索命中、进度跨刷新持久、学习路径完成标记、深色模式、控制台零错误。报告在 `_build/verify_report.json`。

**两个深推页**：`check_render.py`（390×844 视口）报告 11 章 / 10 章全部通过，公式内裸 `<` 为 0，残留 `$` 为 0，无横向溢出；KaTeX 元素数分别为 105 / 41（DOM 计数，非截图目测）。折叠推导可点开与收起、抽屉目录 11 项、章节导航按钮均实测有效。

**交付包**：解压到 `/tmp/smoke` 独立目录后实测——`index.html` 可开（标题「学习总手册」）、第 14 章 28 段正常渲染、深推页 KaTeX 41 处、单书伴侣可开，控制台无报错。

**一个已知偏差**：知识库正文（`chapters/`、`concepts/`）里的公式一律转成了纯文本，因为单书伴侣的渲染器不支持 KaTeX；只有两个深推页内联了 KaTeX 与 base64 字体。这导致正文里的余弦公式写成 `cosθ = (a·b)/(‖a‖‖b‖)` 这样的文本形式，可读但不美观。

## 六、取舍与版权

- `_work/`、`_build/`、`_shots/` 不影响站点运行；要更轻的公开仓库，删掉这三个目录再推送（`index.html` 与两个深推页都是自包含单文件）。
- `_work/raw/` 是原书抽取文本，仅供核对与重建，公开前请确认版权边界。原书 PDF 未署名作者，在线阅读地址：https://jimmysong.io/zh/book/agentic-design-patterns/ 。
- 内容基线按「大二数学/计科」写：跳过四则运算级铺垫，重点压在模式的设计动机与失效条件；因此章节里不重复解释向量、概率等前置概念，只在深推页里补。
- 交付模式 `full` 是在用户未明确选择 `final`/`full` 时的默认推进；若只要轻量版，可用 `package_delivery.py --mode final` 重新打包。
