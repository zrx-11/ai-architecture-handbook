## 第 1 章

### q01（单选）DeepSeek 四代结构主线的最合理排序是？
- A. dense → MoE → MLA + MoE → 稀疏注意力/百万上下文
- B. MoE → dense → MLA → CNN
- C. dense → MLA → MoE → RNN
- D. V2 → V3 → V1 → V4
**答案**：A
**解析**：先 dense，再把 FFN 拆成 MoE，再用 MLA 压 KV，最后用 DSA/CSA 做稀疏长上下文。

### q02（单选）模型卡写“671B/37B”，这两个数分别指？
- A. 671B 激活，37B 总参数
- B. 671B 总参数，37B 每 token 激活
- C. 两者都是总参数
- D. 两者都是激活参数
**答案**：B
**解析**：MoE 的总参数要全装，激活参数决定每 token 算力。

### q03（单选）哪个 checkpoint 第一次把 `architectures` 换成 `DeepseekV32ForCausalLM`？
- A. V3
- B. V3.1
- C. V3.2-Exp
- D. V3.1-Terminus
**答案**：C
**解析**：V3.2-Exp 引入 DSA，结构标识随之变化；V3.1 仍是 V3 结构。

## 第 3 章

### q07（单选）DeepSeekMoE 16B 每 token 选几个路由专家？
- A. 2
- B. 6
- C. 8
- D. 64
**答案**：B
**解析**：top-6 路由专家，另有 2 个共享专家始终激活。

### q08（单选）共享专家的主要作用是什么？
- A. 学通用知识，减少路由专家重复学习
- B. 只处理英文
- C. 替代注意力
- D. 只做负载均衡
**答案**：A
**解析**：共享专家始终激活，兜住通用语言知识；路由专家专注细分知识。

### q09（单选）MoE 的显存占用主要按什么估？
- A. 激活参数
- B. top-k
- C. 总参数
- D. 词表大小
**答案**：C
**解析**：所有专家都要存，显存按总参数；算力按激活参数。

## 第 4 章

## 第 6 章

### q16（单选）R1-Zero 与 R1 的关键区别是什么？
- A. 有没有冷启动 SFT
- B. 参数规模不同
- C. 注意力不同
- D. 词表不同
**答案**：A
**解析**：R1-Zero 从 Base 直接纯 RL；R1 先做冷启动 SFT，再做推理 RL、拒绝采样和再对齐。

### q17（单选）GRPO 的优势怎么算？
- A. 用 value model 估
- B. 组内奖励减均值、除以标准差
- C. 直接取奖励
- D. 用人类偏好打分
**答案**：B
**解析**：GRPO 对同一题采一组回答，做组内标准化；全对/全错组标准差为 0，没有梯度。

### q18（单选）R1 蒸馏的 Qwen-7B 学生模型是什么架构？
- A. DeepSeek V3 MoE
- B. MLA
- C. Qwen dense
- D. CNN
**答案**：C
**解析**：蒸馏学生是 Qwen2.5/Llama dense，继承 R1 的输出分布，不继承 DeepSeek MoE 结构。

## 第 7 章

### q19（单选）V3.2-Exp 的结构变化是什么？
- A. 换成 dense
- B. 引入 DSA 稀疏注意力
- C. 去掉 MoE
- D. 改成 CNN

### q20（单选）V3.2 的“思考融入工具调用”指什么？

- D. 两个模型分别做
**答案**：A
**解析**：V3.2 在思考模式下可以多轮“想 → 调工具 → 再想”，同时支持思考/非思考工具调用。

### q21（单选）V3.2-Speciale 的主要限制是什么？
- A. 没有公开权重
- B. 不支持中文
- C. 不支持工具调用，偏研究评测
- D. 只有 7B
**答案**：C

### q26（单选）CED 的解码器全局 KV 来自哪里？
- A. 每层自己算
- B. 输入 embedding

### q27（单选）CSA2 的 Reuse 模式复用了什么？

- D. 完全重算
**答案**：A
**解析**：Reuse 复用主 KV 和上一层选好的 top-k 索引；分布漂移时改用 Reindex。

### q28（单选）V4.1 的 890 B/token 指什么？

**答案**：B
**解析**：890 B/token 是全局 KV，不含持久 KV、SWA、Engram、激活和框架开销。
