# DSA（DeepSeek 稀疏注意力）

- **难度**：高难 | **涉及章节**：第 7–8 章

## 一句话定义

DSA 用轻量索引器给每个 query 选 top-k 个历史 token，只对这些 token 做注意力。

## 为什么重要

V3.2 和 V4 的长上下文成本能降下来，DSA 是核心结构。它把注意力从 $O(L^2)$ 拉向 $O(Lk)$。

## 详解

标准注意力每个 query 看所有历史 token。DSA 分两步：

1. 索引器给每个 query-历史 token 对打分。
2. 每个 query 只保留分数最高的 $k$ 个 token，做 $QK^\top$ 和加权。

索引器很轻，精算只发生在 top-k 上。代价是索引器有计算、top-k 可能选错、实现复杂。

V3.2-Exp 首次引入 DSA，API 价格降 50% 以上；V4 把 DSA 和 token 压缩结合。

## 常见误解

- 别以为 DSA 是把注意力矩阵随机稀疏化——它是可学习索引 + top-k。
- 别以为 DSA 只省计算——它还省 KV 读取带宽。
- 别以为 top-k 越大越好——k 大成本高，k 小丢信息。
