# CSA 与 HCA

- **难度**：高难 | **涉及章节**：第 8 章

## 一句话定义

CSA 把每 $m$ 个 token 的 KV 压成一个条目再做稀疏选择；HCA 用更粗的块表示极远端历史。

## 为什么重要

V4 的 1M 上下文不是只靠 DSA，而是 CSA/HCA/SWA 分层：近处精确、中程压缩、远端粗粒度。

## 详解

- CSA：$m=4$，每 4 个 token 压一个条目；Pro top-k 1024，Flash top-k 512。
- HCA：$m'=128$，每 128 个 token 压一个块；负责极远端。
- SWA：最近 128 token 精确窗口，保细节。

三条路径按距离分工，输出汇总。压缩会丢细节，所以不能只用一种。

## 常见误解

- 别以为 CSA 是平均池化——它是可学习压缩 + top-k。
- 别以为 HCA 能替代 SWA——极远端块表示会丢局部细节。
- 别以为 1M 上下文只靠 RoPE 外推——成本结构才是瓶颈。
