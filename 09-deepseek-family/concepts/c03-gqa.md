# GQA（分组查询注意力）

- **难度**：基础 | **涉及章节**：第 2 章

## 一句话定义

GQA 让多个查询头共享一组 K/V，减少 KV cache 和注意力带宽。

## 为什么重要

DeepSeek-LLM 67B 用 64 个查询头、8 个 KV 头，这是第一代省显存的关键。理解 GQA，才能理解后面 MLA 为什么要走另一条路。

## 详解

标准 MHA：每个查询头都有自己的 K/V，KV cache 每 token 每层是 $2hd_h$ 个数。GQA 把 $h$ 个查询头分成 $g$ 组，每组共享一套 K/V，KV cache 降到 $2gd_h$。

67B 的 $h=64,g=8$，KV cache 是 MHA 的 1/8。查询头仍然有 64 个，表达能力保留一部分；K/V 投影矩阵变小，推理带宽下降。

代价是多个查询头看到同一组 K/V，模型容量受影响。GQA 是在 MHA 和 MQA（只有 1 组 KV）之间的折中。

## 常见误解

- 别以为 GQA 是“只有 8 个头”——查询头还是 64 个。
- 别以为 GQA 只省显存——它还省注意力带宽，提升 decode 速度。
- 别以为 GQA 能替代 MLA——MLA 压的是潜向量，压缩比更高，但计算更复杂。
