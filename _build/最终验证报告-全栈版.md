## 四、构建口径

```bash
# 单书伴侣（9 本）
python3 build_companion.py --manifest <book>/manifest.json --out <book>/<slug>学习伴侣.html --offline auto
python3 apply_visual_theme.py --file <book>/<slug>学习伴侣.html

# 总入口（9 本）
python3 build_handbook.py --root . --out index.html --cross-dir 00-跨书总览 --offline auto
python3 apply_visual_theme.py --file index.html
python3 _build/patch_home.py
```

注意顺序：构建会覆盖首页与单书伴侣，视觉注入必须在构建之后；`patch_home.py` 负责全栈 7 步主线、9 本统计、标题与首页品牌替换。
