00课程概览：两种完全不同的结构

CNN 处理图像，利用“局部模式在整张图上重复出现”；RNN 处理序列，利用“上一步的状态传到下一步”。这门课把两者的核心机制、手算例子和梯度问题讲清楚，最后落到它们为什么会被 Transformer 取代一部分。

01卷积：滑动窗口

卷积核是一个小矩阵，在输入上滑动，每到一个位置就和覆盖区域逐项相乘再求和，得到一个输出值。

例：3×3 卷积核在 5×5 输入上滑动，不加填充、步长 1，输出尺寸：

$$H_{\text{out}}=\frac{H_{\text{in}}-K+1}{S}=\frac{5-3+1}{1}=3$$

所以输出 3×3。参数量是 $3\times3=9$ 个权重，加上 1 个偏置。整张图共享这 9 个权重。

手算一个位置

输入 3×3 区域：

1 2 3
4 5 6
7 8 9

卷积核：

1 0 -1
1 0 -1
1 0 -1

逐项乘再加：$1-3+4-6+7-9=-6$。这个核在检测“左右方向的边缘”。

卷积的两个关键：局部连接（每次只看一小块）和权重共享（同一个核扫全图）。这让图像模型的参数量远小于全连接。

02池化与感受野

池化把一小块区域压成一个值。最大池化取最大值，平均池化取平均。

2×2 最大池化，步长 2，输入 4×4，输出 2×2。每个输出是对应 2×2 区域的最大值。

作用

  • 降低分辨率，减少计算量。
  • 让模型对小范围平移不那么敏感。
  • 扩大后续层的感受野。

感受野是输出上一个位置“能看到”输入多大区域。堆两层 3×3 卷积（无池化），第二层一个位置能看到 5×5；堆三层能看到 7×7。

$$R_n=R_{n-1}+(K_n-1)\prod_{i

步长越大，感受野扩得越快，但空间细节丢得越多。

池化不是必须的。很多现代 CNN 用步长卷积代替池化，保留更多可学习性。

03一个 CNN 的结构

典型 CNN：卷积 → 激活 → 池化，重复几次，最后接全连接分类头。

层作用输出
卷积 3×3, 32 通道提取局部边缘/纹理特征图 32 张
ReLU加非线性同尺寸
最大池化 2×2降采样宽高减半
卷积 3×3, 64 通道组合成更大模式64 张特征图
全局平均池化每张图压成一个数64 维向量
全连接映射到类别10 类 logits

参数量

3×3 卷积，输入 3 通道，输出 32 通道：$(3\times3\times3+1)\times32=896$ 个参数。与图像大小无关。

通道数就是“用多少种不同的卷积核去扫”。输入 3 通道（RGB），每个输出通道对所有输入通道各有一个核。

04经典 CNN 与残差

LeNet 是最早的卷积网络之一，用于手写数字。AlexNet 把 CNN 推上 ImageNet。VGG 用连续 3×3 卷积堆深。ResNet 引入残差连接。

残差连接

$$y=x+F(x)$$

反向传播时，梯度一条经过 $F$，一条直接经过 $x$。直接路径让梯度不容易在深层网络中消失。

没有残差时，20 层网络的梯度要连乘 20 个局部导数；有残差时，至少有一条路径的导数是 1。

ResNet 的核心不是“更深”，而是“让深网络可训练”。残差连接后来也被 Transformer 借走。
残差要求 $x$ 和 $F(x)$ 形状一致。形状不一致时要用 1×1 卷积或线性投影对齐。

05RNN：把状态传下去

RNN 按时间步读序列。每个时间步接受当前输入 $x_t$ 和上一步隐状态 $h_{t-1}$，算出新状态：

$$h_t=\tanh(W_xx_t+W_hh_{t-1}+b)$$

输出可以用 $h_t$ 再接一层。所有时间步共享同一组 $W_x,W_h$。

手算一个标量 RNN

设 $W_x=1$，$W_h=0.5$，$b=0$，输入序列 $[1,2,3]$，初始 $h_0=0$：

h1 = tanh(1*1 + 0.5*0) = tanh(1) ≈ 0.762
h2 = tanh(1*2 + 0.5*0.762) = tanh(2.381) ≈ 0.983
h3 = tanh(1*3 + 0.5*0.983) = tanh(3.492) ≈ 0.998

隐状态把前面的信息压缩进来了。

普通 RNN 记不住太长。序列一长，早期信息在每步被反复混合，梯度也会连乘很多次。

06LSTM 与 GRU

LSTM 用门控控制“记多少、忘多少、输出多少”。核心是细胞状态 $c_t$，它有一条相对直接的传递路径。

门作用公式
遗忘门旧状态保留多少$f_t=\sigma(W_f[h_{t-1},x_t]+b_f)$
输入门新信息写进多少$i_t=\sigma(W_i[h_{t-1},x_t]+b_i)$
候选状态新信息本身$\tilde c_t=\tanh(W_c[h_{t-1},x_t]+b_c)$
输出门当前输出多少$o_t=\sigma(W_o[h_{t-1},x_t]+b_o)$
$$c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t,\qquad h_t=o_t\odot\tanh(c_t)$$

$\odot$ 是逐项乘。遗忘门接近 1 时，旧信息保留；接近 0 时，忘掉。

GRU 把细胞状态和隐状态合并，只有更新门和重置门，参数更少，效果常接近 LSTM。

07seq2seq 与注意力

seq2seq 用一个编码器把输入序列压成状态，再用解码器一步步生成输出。机器翻译、摘要都用过。

瓶颈

编码器最后只给一个向量，长句信息全压在里面，解码器很难记住开头。

注意力

解码器每生成一个词，回头看一眼编码器的所有状态，按相关性加权：

$$\alpha_{t,i}=\frac{\exp(e_{t,i})}{\sum_j\exp(e_{t,j})},\qquad c_t=\sum_i\alpha_{t,i}h_i$$

$e_{t,i}$ 是解码器状态和编码器状态 $h_i$ 的打分。$c_t$ 是上下文向量。

注意力让解码器不必把整句压成一个向量。Transformer 把这套机制做成“只有注意力，没有循环”，并行度更高。

08梯度消失与长序列

RNN 的反向传播要沿时间步连乘。每一步都有 $W_h$ 和激活函数的导数。

如果每步局部导数平均 0.5，传 20 步：$0.5^{20}\approx9.5\times10^{-7}$，梯度几乎没了。反过来平均 1.5，20 步后约 3325，梯度爆炸。

处理

  • LSTM/GRU 的门控和细胞状态直通路径。
  • 梯度裁剪，限制范数。
  • 更短的序列、截断沿时间反向传播。
  • 用注意力直接连接远距离位置。
Transformer 不是“没有梯度问题”，而是用残差、LayerNorm 和注意力让远距离依赖的路径更短。

09常见误解与自测

四个误解

  • “卷积就是数学里的卷积积分”：深度学习框架大多实现的是互相关，不翻转核，习惯上仍叫卷积。
  • “池化越多越好”：池化丢空间信息，检测小目标时可能有害。
  • “LSTM 能记住无限长”：门控缓解，不消除；太长仍会忘。
  • “Transformer 完全不需要卷积”：视觉 Transformer 常在前端用卷积 patch embedding，混合结构很常见。
