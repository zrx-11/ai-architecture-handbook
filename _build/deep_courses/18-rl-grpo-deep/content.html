00课程概览：R1 的 RL 到底在优化什么

这门课把强化学习的最小必要知识串起来：状态、动作、奖励、策略梯度、PPO，然后落到 DeepSeek-R1 用的 GRPO。重点不是背算法名，而是看懂“没有价值网络时，优势怎么估”。

01MDP：状态、动作、奖励

强化学习的基本设定是马尔可夫决策过程，四件事：状态 $s$、动作 $a$、转移 $P(s'\mid s,a)$、奖励 $r$。

智能体在状态 $s_t$ 选动作 $a_t$，环境给奖励 $r_t$，转到下一个状态 $s_{t+1}$。目标是让长期累计奖励最大。

$$G_t=r_t+\gamma r_{t+1}+\gamma^2r_{t+2}+\cdots$$

$\gamma\in[0,1]$ 是折扣因子。越远期的奖励权重越小。

语言模型怎么套进去

把“生成一个 token”看成一步：

RL 概念语言模型里
状态 $s_t$已经生成的 prompt + 前面的 token
动作 $a_t$从词表里选下一个 token
策略 $\pi_\theta(a\mid s)$模型输出的下一个 token 概率
奖励 $r$整条回答结束后，由奖励模型或规则给分

注意：语言模型通常只在整条回答结束时拿一个奖励，中间 token 没有即时奖励。

02策略、价值与优势

策略 $\pi(a\mid s)$ 是在状态 $s$ 选动作 $a$ 的概率。价值函数衡量“从某个状态出发，按当前策略能拿多少回报”：

$$V^\pi(s)=E_{\pi}[G_t\mid s_t=s]$$

动作价值 $Q^\pi(s,a)$ 是“先选动作 a，再按策略走”的期望回报。

优势

优势 $A(s,a)=Q(s,a)-V(s)$：这个动作比“平均动作”好多少。

策略梯度的直觉：优势为正，提高该动作概率；优势为负，降低该动作概率。

$$\nabla_\theta J(\theta)=E[\nabla_\theta\log\pi_\theta(a\mid s)A(s,a)]$$
$A$ 只影响方向和权重，$\nabla\log\pi$ 负责告诉参数“怎么改才能提高这个动作的概率”。

03策略梯度与 REINFORCE

最朴素的策略梯度算法叫 REINFORCE：采样一整条轨迹，用回报 $G_t$ 当优势，更新策略。

for each episode:
    sample trajectory (s0,a0,r0,...,sT)
    for each step t:
        G_t = sum of discounted rewards from t
        loss += -log_prob(a_t|s_t) * G_t
    update parameters

负号是因为框架默认最小化损失；我们要最大化 $\log\pi\cdot G$。

方差问题

一条轨迹的回报噪声很大。同一个状态，采样不同，$G_t$ 可能差很多。减一个基线 $b(s)$ 不改变期望，但能降低方差：

$$\nabla J=E[\nabla\log\pi(a\mid s)(G_t-b(s))]$$

常用基线就是价值函数 $V(s)$。减去它，得到的就是优势。

策略梯度是“采样估计”，不是精确求导。batch 太小、奖励噪声太大，训练会抖。

04PPO：别一步改太狠

策略梯度更新一次，策略变了，旧数据就不再来自当前策略。PPO 用重要性采样，让旧数据能多用几次，同时限制更新幅度。

$$r_t(\theta)=\frac{\pi_\theta(a_t\mid s_t)}{\pi_{\theta_{\text{old}}}(a_t\mid s_t)}$$
$$L^{\text{CLIP}}=\min\left(r_tA_t,\ \mathrm{clip}(r_t,1-\epsilon,1+\epsilon)A_t\right)$$

$r_t$ 是新旧策略的概率比。 clip 把比值限制在 $[1-\epsilon,1+\epsilon]$，防止一次更新把某个动作概率拉得太高或压得太低。

直观理解

如果优势为正，PPO 想提高这个动作概率，但最多提高到旧概率的 $1+\epsilon$ 倍；优势为负，最多降到 $1-\epsilon$ 倍。一步只走一点。

PPO 通常还要加价值损失和熵奖励。价值网络帮助估优势；熵奖励鼓励探索，防止策略过早变确定。

05奖励模型与 RLHF

大模型 RL 的奖励通常不是环境给的，而是人偏好训出来的奖励模型。流程：

  1. 让模型对同一个 prompt 生成多条回答。
  2. 人给回答排序：A 比 B 好。
  3. 训练奖励模型 $r_\phi(x,y)$，让好回答得分高。
  4. 用 RL 优化策略，让奖励模型给高分。

奖励模型的损失常写成 Bradley-Terry：

$$L=-\log\sigma(r_\phi(x,y_w)-r_\phi(x,y_l))$$

$y_w$ 是偏好回答，$y_l$ 是被拒回答。差值越大，越确信。

奖励模型会被“钻空子”。策略可能找到得分高但人看着很差的回答，这叫 reward hacking。所以还要加 KL 约束，别让策略离原模型太远。

06GRPO：用组内相对分当优势

PPO 需要一个和策略同样大的价值网络，显存翻倍。GRPO 换了个估优势的办法：对同一个问题采样一组回答，用组内奖励的相对位置当优势。

设一组奖励 $r_1,\dots,r_G$，组均值 $\bar r$，标准差 $\sigma_r$：

$$A_i=\frac{r_i-\bar r}{\sigma_r+\epsilon}$$

奖励高于组平均，优势为正；低于平均，优势为负。不需要价值网络。

手算

同一道数学题采样 4 条回答，奖励 $[1,0,1,0]$。均值 0.5，标准差 0.5。优势：$[1,-1,1,-1]$。两条正确被推高，两条错误被压低。

GRPO 的核心不是“组内归一化”这一个技巧，而是整条链路：组采样、规则/模型奖励、相对优势、KL 约束、策略更新。少了任何一环都不成立。

07KL、熵与训练稳定性

RL 微调会让模型偏离原来的语言模型。偏离太远，可能语言崩坏、胡说八道。KL 惩罚把新策略拉住在参考模型附近：

$$L=L^{\text{RL}}+\beta\,\mathrm{KL}(\pi_\theta\|\pi_{\text{ref}})$$

$\beta$ 越大，越不敢偏离。KL 不是距离，不满足对称性，但能衡量两个分布的差异。

熵

$$H(\pi)=-\sum_a\pi(a)\log\pi(a)$$

熵高，分布平，探索多；熵低，分布尖，利用多。训练初期常加熵奖励鼓励探索，后期降低。

KL 估计有偏，采样太少时噪声大。实际实现常用 k3 估计器，并对 β 做自适应。

08R1 的训练映射

R1 的技术报告把 RL 放在后训练阶段，核心目标是让模型学会长链推理。把前面的概念对上去：

R1 里的环节对应本课概念
同一个问题采样多条回答组采样
答案对错、格式规则给奖励规则奖励
组内相对分GRPO 优势
限制模型别跑偏KL 惩罚
冷启动、拒绝采样、蒸馏数据与策略初始化，不是单一 RL 算法

R1-Zero 直接从基座做 RL，不先做监督微调，能看到推理能力自己长出来，但输出可读性差。R1 加了冷启动数据和多阶段训练，把可读性和稳定性补上。

“纯 RL 就能变强”是简化说法。R1 的完整流水线仍包含数据构造、SFT、RL、拒绝采样和蒸馏。

09常见误解与自测

四个误解

  • “RL 就是给奖励，模型自己会学”：奖励设计、采样、优势估计、KL 约束缺一不可。
  • “GRPO 完全不用价值函数，所以比 PPO 简单很多”：省掉价值网络，但组采样和奖励设计更吃工程。
  • “KL 越大越安全”：太大模型不敢学新东西，奖励信号被压死。
  • “R1 是一个全新架构”：R1 主要换训练目标与数据流程，骨架仍是 DeepSeek 系列模型。
