00课程概览：从概率到“模型好不好”

这门课不背算法，只回答三个问题：模型输出的概率是什么意思？训练时最小化的损失从哪来？评估时 precision、recall、AUC 分别在说什么？

学完你能做到

  • 用贝叶斯公式算一个简单的后验概率。
  • 从最大似然推出交叉熵，并手算一个三分类的损失。
  • 解释平方损失为什么对应高斯噪声假设。
  • 用混淆矩阵算 precision、recall、F1。
  • 识别数据泄漏和错误的交叉验证。
前置：会分数、对数、求和符号。看到 $\sum$ 会愣住的话，先把它读成“把每一项加起来”。

01条件概率与贝叶斯

条件概率 $P(A\mid B)$ 读作“在 B 发生的条件下，A 发生的概率”。定义是：

$$P(A\mid B)=\frac{P(A\cap B)}{P(B)}$$

贝叶斯公式把“因果”翻过来：

$$P(A\mid B)=\frac{P(B\mid A)P(A)}{P(B)}$$

例子：某种病患病率 1%，检测阳性时真患病的概率不是 99%。设检测灵敏度 $P(+\mid 病)=0.99$，假阳性 $P(+\mid 无病)=0.05$。先算总阳性率：

$$P(+)=0.99\cdot0.01+0.05\cdot0.99=0.0099+0.0495=0.0594$$

后验：

$$P(病\mid +)=\frac{0.99\cdot0.01}{0.0594}\approx0.167$$

阳性只有 16.7% 真患病。原因是健康人基数大，假阳性把阳性池子撑大了。这就是“基率”的作用。

不要只看灵敏度。评估一个模型时，正负样本比例会直接改变 precision，哪怕 recall 没变。

02最大似然与交叉熵

分类模型输出一个概率分布 $p_1,\dots,p_K$。训练集里真实类别是 $y$，我们想让模型给真实类别的概率尽量大。最大似然就是：

$$\max_\theta \sum_{(x,y)}\log p_\theta(y\mid x)$$

加负号变成最小化，就是交叉熵：

$$\mathcal L_{\mathrm{CE}}=-\sum_{(x,y)}\log p_\theta(y\mid x)$$

如果标签是 one-hot，只有真实类别那一项非零：$\mathcal L=-\log p_{\text{true}}$。

手算：三分类输出 $[0.7,0.2,0.1]$，真实类别是第 1 类，损失 $-\log0.7\approx0.357$。如果输出 $[0.1,0.2,0.7]$，真实仍是第 1 类，损失 $-\log0.1\approx2.303$。错得越自信，罚得越重。

真实类别模型给真实类的概率交叉熵
第 1 类0.70.357
第 1 类0.12.303
第 1 类0.014.605
交叉熵不是“错误率”，它是负对数似然。预测概率越接近 0，损失越快趋向无穷；所以模型会对“非常自信但错了”的样本给大梯度。

03平方损失与高斯噪声

回归模型输出 $\hat y$，真实值 $y$。平方损失：

$$\mathcal L=(\hat y-y)^2$$

对 $\hat y$ 求导：

$$\frac{\partial \mathcal L}{\partial \hat y}=2(\hat y-y)$$

为什么老是平方？如果假设 $y=\hat y+\epsilon$，$\epsilon\sim\mathcal N(0,\sigma^2)$，那么给定 $\hat y$ 时 $y$ 的似然是高斯。取负对数，常数项之外就是 $\frac{(y-\hat y)^2}{2\sigma^2}$。最小化平方损失等价于在高斯噪声假设下做最大似然。

平方损失对异常值敏感：误差 10 会被平方成 100。数据有长尾异常值时，绝对值损失（L1）或 Huber 损失更稳。

分类用交叉熵，回归用平方损失，不是随意搭配。它们对应不同的概率假设：分类是伯努利/类别分布，回归是高斯的。

04偏差与方差

模型的期望误差可以拆成三块：

$$\mathbb E[(y-\hat f(x))^2]=\text{偏差}^2+\text{方差}+\text{噪声}$$

偏差：模型平均预测偏离真实函数多远。方差：换一批训练数据，模型预测波动多大。

状态训练误差验证误差典型原因
欠拟合高高模型太简单、特征太少、训练不足
过拟合低高模型太复杂、数据太少、训练太久
合适低低容量与数据匹配

不要只看训练 loss。训练 loss 降到 0 不代表模型学会了规律，可能只是记住了样本。

“偏差-方差权衡”不是玄学：增加模型容量通常降偏差、升方差；增加数据通常降方差；正则化通常升偏差、降方差。

05过拟合与正则化

正则化是给模型加约束，让它不要为了拟合噪声而疯狂摆动。

L2 正则

$$\mathcal L_{\mathrm{total}}=\mathcal L_{\mathrm{data}}+\lambda\sum_i w_i^2$$

把权重往 0 拉，惩罚大权重。梯度多一项 $2\lambda w_i$。

L1 正则

$$\mathcal L_{\mathrm{total}}=\mathcal L_{\mathrm{data}}+\lambda\sum_i|w_i|$$

L1 更容易把不重要的权重压到正好 0，产生稀疏解。

Dropout

训练时随机把一部分神经元输出置 0，逼网络不要依赖某一条路径。推理时关闭，并按保留概率缩放，保持期望不变。

早停

验证 loss 连续几轮不降就停。它是最便宜的正则化，不用改模型结构。

正则化不是越多越好。$\lambda$ 太大，模型被压得只会输出常数，变成欠拟合。

06混淆矩阵与 P/R/F1

二分类的四个格子：

预测正预测负
真实正TPFN
真实负FPTN

三个最常用的指标：

$$\text{Precision}=\frac{TP}{TP+FP},\qquad \text{Recall}=\frac{TP}{TP+FN}$$
$$F_1=\frac{2\,\text{Precision}\cdot\text{Recall}}{\text{Precision}+\text{Recall}}$$

手算：100 个样本，TP=30，FP=10，FN=20，TN=40。

  • Precision = 30/40 = 0.75：预测为正的里面，75% 真为正。
  • Recall = 30/50 = 0.60：真实为正的里面，抓到了 60%。
  • F1 = 2×0.75×0.60/1.35 ≈ 0.667。
  • Accuracy = (30+40)/100 = 0.70，但在正负不平衡时会骗人。
Precision 关心“别误报”，Recall 关心“别漏报”。医疗筛查通常偏 Recall，垃圾邮件拦截通常偏 Precision。没有统一答案，看漏报和误报哪个代价大。

07ROC、AUC 与 PR 曲线

分类器输出的是分数，不是硬标签。换一个阈值，TPR 和 FPR 都会变：

$$\text{TPR}=\frac{TP}{TP+FN},\qquad \text{FPR}=\frac{FP}{FP+TN}$$

把阈值从高到低扫一遍，得到 ROC 曲线。AUC 是曲线下面积，意思是“随机抽一个正样本和一个负样本，模型给正样本更高分的概率”。

AUC=0.5 等于瞎猜，AUC=1 是完美排序。AUC 只看排序，不看具体阈值，所以它对类别不平衡不敏感；也正因为如此，极度不平衡时它可能看起来很好，实际 precision 很差。

正样本只有 1% 时，看 PR 曲线通常比 ROC 更有意义。ROC 的 FPR 分母是负样本，负样本很多时，少量 FP 在 FPR 上不明显，但在 precision 上会很痛。

08数据泄漏与交叉验证

数据泄漏是评估里最隐蔽的错：训练时不小心看到了测试信息，分数虚高，上线就崩。

泄漏类型例子正确做法
预处理泄漏在全量数据上算均值/方差再标准化只用训练折算，再应用到验证折
时间泄漏用未来数据预测过去按时间切分，训练集早于验证集
分组泄漏同一用户的不同记录同时进训练和测试按用户/设备分组切分
目标泄漏特征里包含标签的直接后代检查特征生成时间与可用性

k 折交叉验证：把数据切成 k 份，每次拿 1 份做验证，其余训练，最后平均。它降低单次切分的偶然性，但不能修复泄漏。

$$\text{CV}=\frac1k\sum_{i=1}^k \text{score}_i$$

时间序列不能随机打乱做 k 折，要用滚动窗口或按时间切分。

09常见误解与自测

先排掉五个误解

  • “准确率高就是模型好”：正负 99:1 时，全预测负也有 99% 准确率。
  • “AUC 高，precision 一定高”：不一定。AUC 看排序，precision 看阈值上的误报。
  • “交叉验证可以防止过拟合”：它只是更稳地估计泛化误差，不改变模型容量。
  • “正则化越强越好”：太强会欠拟合。
  • “训练 loss 低，测试也不会差”：可能已经记住了训练集，测试集才是检验。
