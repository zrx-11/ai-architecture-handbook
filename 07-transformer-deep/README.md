# Transformer 从零推导（深潜专题）

来源：`zrx-11/transformer` 仓库，原样合并，保留其自包含 HTML、内联 KaTeX 与交互式折叠推导。

## 这套课有什么

15 个部分：课程概览、初中数学基础、语言建模与词嵌入、位置编码、注意力、多头注意力、残差与归一化、前馈网络、编码器、解码器与掩码、训练与损失、推理与生成、BERT/GPT 扩展、代码实现、知识图谱。

原课标注：63 个提示框、179 个推导步骤、60 个公式块、7 张表格。每个公式都有数值例子，推导默认展开，可逐节折叠。

## 怎么用

直接打开 `index.html`。手机端左上角“目录”弹出章节列表；桌面端左侧目录常驻。每章底部有上一章/下一章按钮。

## 在整套学习系统里的位置

- 先读 `01-foundations` 第 3–4 章，建立注意力与 Transformer 一层楼的最小骨架。
- 再进这套深潜课，把位置编码、多头、掩码、训练与生成逐段推完。
- 最后读 `02-paper-teardown` 的 V4/V4.1，看 DeepSeek 在标准 Transformer 上改了哪些地方。

这套课讲标准 Transformer；DeepSeek 的 MLA、CSA、CSA2 是另一条演进线，不要混为一谈。
