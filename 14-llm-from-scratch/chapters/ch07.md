# 第 7 章：预训练：损失、学习率与稳定性

- **难度**：★★★ | **预估学时**：2 小时 | **前置**：第 6 章

## 学习目标

1. 写出下一个 token 的交叉熵损失；
2. 解释 warmup、余弦退火、梯度累积、梯度裁剪各自解决什么；
3. 用 `6ND` 估算训练算力，并说明它的边界。

## 一句话核心

预训练是在做“压缩”：把海量文本里的可预测规律压进参数；loss 下降不等于模型变聪明，它只说明模型更会预测训练分布。

## 7.1 损失

对序列 `x_1...x_T`，模型在位置 `t` 看前 `t-1` 个 token，预测 `x_t`：

$$
\mathcal{L}=-\frac{1}{T}\sum_{t=1}^{T}\log p_\theta(x_t\mid x_{<t})
$$

实现时把输入右移一位做 label；padding 位置用 `-100` 忽略。困惑度 `PPL=exp(loss)`，但不同 tokenizer 的 PPL 不可直接比。

## 7.2 训练循环的最小骨架

```python
for batch in loader:
    x, y = batch               # x: [B,T], y: [B,T]
    logits = model(x)          # [B,T,V]
    loss = cross_entropy(logits.reshape(-1,V), y.reshape(-1))
    loss.backward()
    clip_grad_norm_(model.parameters(), 1.0)
    optimizer.step(); optimizer.zero_grad()
```

真实训练还要：混合精度、梯度累积、分布式 all-reduce、检查点、断点续训、日志和随机种子。

## 7.3 学习率与稳定性

- warmup：前几百/几千步从很小线性升到峰值，避免早期大梯度破坏参数。
- 余弦退火：后段慢慢降，减少震荡。
- 梯度裁剪：限制范数，防爆炸。
- 权重衰减：抑制过大参数，但 norm/bias 通常不 decay。
- 梯度累积：小显存模拟大 batch，但 batch norm/统计量要小心。

常见故障：loss 变 NaN（学习率太大、fp16 溢出、数据有坏样本）、loss 不降（标签错位、mask 错、学习率太小）、loss 降但生成乱（数据重复、模板错、评估集泄漏）。

## 7.4 6ND 算力账本

训练 FLOPs 近似：

$$
C \approx 6ND
$$

`N` 是参数量，`D` 是训练 token 数。例：`N=7e9, D=1e9` → `C≈4.2e19` FLOPs。这个公式不含 attention 的二次项、通信和低效算子，所以是下界量级，不是实际电费单。

“每个参数 20 token”是 Chinchilla 的经验参考，不是所有模型都必须照做。数据质量、模型规模、目标任务都会改变最优配比。
