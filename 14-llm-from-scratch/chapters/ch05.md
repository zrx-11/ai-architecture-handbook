# 第 5 章：注意力：Q、K、V、mask 与多头

- **难度**：★★★ | **预估学时**：2 小时 | **前置**：第 4 章

## 学习目标

1. 手算一个 3 token、2 维的注意力分数矩阵；
2. 解释 causal mask 和 scaling 的作用；
3. 区分 MHA、MQA、GQA 的 KV 头数。

## 一句话核心

注意力就是“每个位置发一个查询，去别的所有位置查资料，再按相关度加权取回信息”。Q/K 决定查谁，V 决定取什么。

## 5.1 一次手算

设 3 个 token，每个 q/k 是 2 维：

```text
q1=[1,0]  q2=[0,1]  q3=[1,1]
k1=[1,0]  k2=[0,1]  k3=[1,1]
```

分数矩阵 `S = Q K^T`：

```text
      k1  k2  k3
q1    1   0   1
q2    0   1   1
q3    1   1   2
```

除以 `sqrt(2)` 得 `0.71, 0, 0.71 / ...`。再对每一行做 softmax，得到注意力权重；权重乘以 V 并求和，就是这一层的输出。

为什么要除以 `sqrt(d_k)`？点积的方差随维度增大，不缩放会让 softmax 过尖，梯度变小。`sqrt(d_k)` 是把方差拉回常数尺度的最简做法。

## 5.2 causal mask

语言模型不能看见未来。对位置 `i`，只允许看 `<=i` 的 key：

```text
mask[i,j] = 0      if j <= i
             -inf   if j > i
```

`-inf` 过 softmax 变成 0。没有 mask，模型训练时会偷看下一个 token，loss 看起来很好，推理时却不会生成。

## 5.3 多头

把 `d=512` 分成 `H=8` 个头，每头 `d_head=64`。每个头有自己的 Q/K/V 投影，独立做注意力，再拼回 `512`。多头不是“八个模型”，而是让不同的头学不同的关系模式。

## 5.4 MHA、MQA、GQA

| 变体 | Query 头 | Key/Value 头 | KV cache | 取舍 |
|---|---|---|---|---|
| MHA | H | H | 最大 | 表达力强，显存贵 |
| MQA | H | 1 | 最小 | 快，但可能损失质量 |
| GQA | H | G（如 8） | 居中 | 常用折中 |

GQA 的关键不是“省一点显存”，而是让长上下文和高并发下的 KV 带宽可控。读模型 config 时，先看 `num_attention_heads` 和 `num_key_value_heads`，不要只看参数量。
