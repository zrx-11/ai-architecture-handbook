## 🔬 Q/K/V 的第一性原理推导：从“加权平均”到注意力

### 先退到你会的东西：加权平均

假设你要给三个同学打分，权重分别是 $0.5, 0.3, 0.2$，分数是 $90, 80, 70$。总分是多少？

$$0.5\times 90 + 0.3\times 80 + 0.2\times 70 = 45 + 24 + 14 = 83$$

这就是**加权平均**：每个数先乘自己的权重，再全部相加。权重加起来等于 1。注意力输出本质上就是这个动作，只不过“分数”换成了每个 token 的 Value 向量，“权重”由 Query 和 Key 的相似度决定。

### 第一步：怎么衡量两个向量“像不像”

两个向量逐位相乘再相加，叫**点积**。拿两个 2 维向量试：

$$\mathbf{a}=[1,0],\quad \mathbf{b}=[1,1]$$

$$\mathbf{a}\cdot\mathbf{b}=1\times 1 + 0\times 1 = 1$$

再拿 $\mathbf{c}=[0,1]$：

$$\mathbf{a}\cdot\mathbf{c}=1\times 0 + 0\times 1 = 0$$

点积为 1 说明 $\mathbf{a}$ 和 $\mathbf{b}$ 方向接近；点积为 0 说明 $\mathbf{a}$ 和 $\mathbf{c}$ 垂直，关系远。点积越大，越“像”。

### 第二步：为什么分数要除以 $\sqrt{d_k}$

如果向量是 128 维，每一维都是 1，点积就是 128。指数 $e^{128}$ 是一个天文数字，softmax 会变成“一个权重 1，其他全 0”。这样梯度几乎没有，训练学不动。

除以 $\sqrt{d_k}$ 相当于把分数拉回个位数。$d_k=128$ 时 $\sqrt{128}\approx 11.3$，128 分的点积变成 11.3，softmax 还能保留梯度。

### 第三步：Q、K、V 为什么要三套矩阵

如果直接拿原始向量 $x_i$ 和 $x_j$ 做点积，只能衡量“原始表示像不像”。但模型需要不同的“提问方式”：
- 找主语时，Query 应该问“谁在做动作”。
- 找修饰语时，Query 应该问“谁在描述名词”。

所以让输入分别乘三个可学习矩阵：

$$\mathbf{q}_i=x_iW_Q,\quad \mathbf{k}_j=x_jW_K,\quad \mathbf{v}_j=x_jW_V$$

$W_Q$、$W_K$、$W_V$ 是训练出来的。Q 和 K 负责“提问与匹配”，V 负责“真正被取走的内容”。分开的好处是：匹配标准和内容可以解耦，模型可以学“按 A 标准找，但取 B 内容”。

### 第四步：把分数变成权重

对第 $i$ 个 token，拿它的 $q_i$ 和所有 $k_j$ 点积，得到分数 $s_{ij}$。然后 softmax：

$$\alpha_{ij}=\frac{e^{s_{ij}}}{\sum_l e^{s_{il}}}$$

分母是把当前 token 对所有 token 的指数分数全部加起来，保证权重总和为 1。

### 第五步：数值算例，自己复核一遍

三个 token，2 维：

- $q_1=[2,0]$
- $k_1=[1,0]$，$k_2=[0,1]$，$k_3=[1,1]$
- $v_1=[10,0]$，$v_2=[0,10]$，$v_3=[4,4]$

点积（先不缩放，$d_k=2$ 时缩放因子 $\sqrt{2}\approx1.414$，这里为演示省略）：

- $q_1\cdot k_1=2$
- $q_1\cdot k_2=0$
- $q_1\cdot k_3=2$

取指数：$e^2\approx7.389$，$e^0=1$，$e^2\approx7.389$，总和 $15.778$。

权重：$[0.468, 0.063, 0.468]$。

输出：

$$0.468[10,0]+0.063[0,10]+0.468[4,4]=[4.68+1.87,\ 0.63+1.87]=[6.55,\ 2.50]$$

检查：权重和 $0.468+0.063+0.468=0.999$，输出两个分量都来自三个 V 的加权，没有凭空多出数字。

### 第六步：为什么要多头

一套 Q/K/V 只能学一种匹配标准。多头让模型并行学多套，每套有自己的 $W_Q/W_K/W_V$。比如 128 头、每头 128 维，各头独立算注意力，拼起来再乘 $W_O$。不同头可以关注相邻词、句法结构、指代关系等不同模式。

### 差生检查

- 符号 $\sum_l$ 表示“对所有 l 求和”，第一次出现已解释。
- 点积、softmax 都在前面章节出现过，这里直接复用。
- 每一步的数值都能用计算器复核。
- 结论给了“为什么这样设计”：分开 Q/K/V 是为了解耦匹配与内容，多头是为了多套匹配标准。
