# 基础篇：从零到 Transformer 测验

## 第 1 章：数字怎么变成“意思”：向量、矩阵与 softmax
### Q1. 一个 2×3 矩阵乘一个 3 维向量，结果是什么形状？
- A. 2×3 矩阵
- B. 3 维向量
- C. 2 维向量
- D. 一个标量
**答案**：C
**解析**：左矩阵两行，每行与 3 维向量做一次加权求和，得到两个数。

### Q2. 对分数 [0, 0, 0] 做 softmax，输出是什么？
- A. [0, 0, 0]
- B. [1/3, 1/3, 1/3]
- C. [1, 0, 0]
- D. [3, 3, 3]
**答案**：B
**解析**：三个 e^0=1，总和 3，各占三分之一。

### Q3. embedding 表在模型里做什么？
- A. 把 token 编号映射成向量
- B. 把向量压缩成标量
- C. 把句子翻译成英文
- D. 计算损失
**答案**：A
**解析**：embedding 表按 token 编号查出一串固定长度的向量。

## 第 2 章：模型怎么学会：参数、损失、梯度
### Q1. 梯度为正时，梯度下降会把参数往哪个方向更新？
- A. 增大
- B. 减小
- C. 不变
- D. 随机
**答案**：B
**解析**：更新规则是减去学习率乘梯度，梯度为正就减小参数。

### Q2. w=1、x=2、y=3，损失 L=(wx-y)^2，对 w 的梯度是多少？
- A. -4
- B. 4
- C. -2
- D. 2
**答案**：A
**解析**：2(wx-y)x = 2(2-3)×2 = -4。

### Q3. 学习率取得过大，训练曲线通常会出现什么？
- A. 收敛更快且稳定
- B. 损失震荡或发散
- C. 参数不再更新
- D. 模型自动变小
**答案**：B
**解析**：步子太大会跨过谷底，损失震荡甚至变成 NaN。

## 第 3 章：注意力机制：一句话里谁该看谁
### Q1. 注意力里真正被加权混合的是哪一项？
- A. Query
- B. Key
- C. Value
- D. 因果掩码
**答案**：C
**解析**：Q 和 K 只用于算分数，输出是 V 的加权和。

### Q2. 分数 [1, 1, 1] 经过 softmax 后的权重是什么？
- A. [1, 0, 0]
- B. [1/3, 1/3, 1/3]
- C. [0.5, 0.5, 0]
- D. [3, 3, 3]
**答案**：B
**解析**：三个 e^1 相等，各占三分之一。

### Q3. 注意力分数为什么要除以 sqrt(d_k)？
- A. 让分数更大
- B. 防止 softmax 过度集中
- C. 增加注意力头数
- D. 去掉位置信息
**答案**：B
**解析**：维度高时点积数值大，softmax 会过度集中，梯度变小。

## 第 4 章：Transformer 一层一层拆
### Q1. 一个 Transformer 层里，残差连接加在哪两处？
- A. 只在注意力后
- B. 只在 FFN 后
- C. 注意力和 FFN 后各一次
- D. 每层最后只加一次
**答案**：C
**解析**：注意力和 FFN 是两个子层，各自带残差。

### Q2. 输入形状 [6, 16] 经过 4 倍 FFN 后，中间层形状是什么？
- A. [6, 16]
- B. [6, 64]
- C. [24, 16]
- D. [6, 4]
**答案**：B
**解析**：隐藏维度 16 放大 4 倍是 64，token 数不变。

### Q3. 为什么位置信息必须显式注入 Transformer？
- A. 让模型知道词序
- B. 减少参数量
- C. 加速训练
- D. 替代注意力
**答案**：A
**解析**：查表得到的 token 向量不含顺序信息，不注入位置就分不清词序。

## 第 5 章：DeepSeek-V3 的三块地基
### Q1. MLA 推理时缓存的核心内容是什么？
- A. 每个头的完整 K 和 V
- B. 低维潜向量和 RoPE key
- C. 只有 Query
- D. 整个隐藏层输出
**答案**：B
**解析**：MLA 缓存压缩后的 c_KV 和承载位置的 RoPE key。

### Q2. DeepSeekMoE 中共享专家的作用是什么？
- A. 只处理英文
- B. 始终激活，兜住通用知识
- C. 只处理数学题
- D. 替代注意力
**答案**：B
**解析**：共享专家对所有 token 生效，减少路由专家重复学习通用知识。

### Q3. MTP 在训练时额外预测哪个位置？
- A. 只预测 t+1
- B. 额外预测 t+2
- C. 预测前一个 token
- D. 随机位置
**答案**：B
**解析**：在位置 t 额外预测 t+2，增加训练信号密度。
