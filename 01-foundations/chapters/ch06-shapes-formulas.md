# 附录：形状、公式与手算清单

- **难度**：★★☆ | **预估学时**：3 小时 | **前置**：第 1–5 章

## 学习目标

学完这篇附录，你能：不查资料写出注意力与 MLA 的张量形状；手算一次 softmax 与梯度更新；用字节公式估算 KV cache；用一个 8 专家例子走完 MoE 路由与负载均衡。

## 一句话核心

读架构图时，先问“这个矩阵乘法的两边形状是什么、结果是什么”，再问“它省了哪部分计算或显存”。形状对不上，后面的解释都是空的。

## 1. 形状检查清单

### 1.1 矩阵乘法

设 $A$ 是 $m\times n$，$B$ 是 $n\times p$，则 $AB$ 是 $m\times p$。中间维度 $n$ 必须相同。

例：$A$ 是 $2\times 3$，$B$ 是 $3\times 4$，结果是 $2\times 4$。不是 $3\times 3$，也不是 $4\times 2$。

### 1.2 注意力的标准形状

设 batch 为 $B$，序列长度为 $L$，模型维度为 $d$，头数为 $h$，每个头维度 $d_h=d/h$。

| 张量 | 形状 |
|---|---|
| 输入 $X$ | $[B,L,d]$ |
| $Q,K,V$ | $[B,L,d]$ |
| 拆头后 | $[B,h,L,d_h]$ |
| 分数 $QK^\top$ | $[B,h,L,L]$ |
| softmax 后权重 | $[B,h,L,L]$ |
| 加权 $AV$ | $[B,h,L,d_h]$ |
| 合并头 | $[B,L,d]$ |

例：$B=2,L=4,d=8,h=2$，则 $d_h=4$；分数形状是 $[2,2,4,4]$，不是 $[2,4,4]$。

### 1.3 为什么要缩放

$QK^\top$ 的每个元素是 $d_h$ 个乘积之和。$d_h$ 越大，点积方差越大，softmax 越容易饱和。缩放因子是 $\sqrt{d_h}$：

$$
\text{Attention}(Q,K,V)=\text{softmax}\left(\frac{QK^\top}{\sqrt{d_h}}\right)V
$$

## 2. softmax 手算

给定分数 $z=[2,1,0]$。

先减最大值 $2$：$[0,-1,-2]$，防止指数溢出。

取指数：$[e^0,e^{-1},e^{-2}]\approx[1,0.368,0.135]$。

求和：$1.503$。

归一化：$[0.665,0.245,0.090]$。三个数相加为 1。

温度 $T$ 的作用：$T=0.5$ 时分数变成 $[4,2,0]$，概率更集中；$T=2$ 时分数变成 $[1,0.5,0]$，概率更平均。

## 3. 梯度下降手算

用一条直线拟合三个点：$(1,2),(2,4),(3,6)$。模型 $y=wx+b$，初始 $w=0,b=0$，学习率 $\eta=0.1$。

预测全为 0，残差 $r_i=\hat y_i-y_i$ 为 $[-2,-4,-6]$。

均方损失 $L=\frac{1}{3}\sum r_i^2$。

梯度：

$$
\frac{\partial L}{\partial w}=\frac{2}{3}\sum r_i x_i=\frac{2}{3}(-2\cdot1-4\cdot2-6\cdot3)=\frac{2}{3}(-28)=-18.67
$$

$$
\frac{\partial L}{\partial b}=\frac{2}{3}\sum r_i=\frac{2}{3}(-12)=-8
$$

更新：

$$
w\leftarrow 0-0.1(-18.67)=1.867,\quad b\leftarrow0-0.1(-8)=0.8
$$

一次更新后，$w$ 已经接近真实斜率 2，$b$ 接近 0。这就是“负梯度方向走一步”。

## 4. 三 token 注意力手算

设三个 token 的 $Q,K$ 都是一维标量，$Q=[1,0,1]$，$K=[1,1,0]$，$V=[2,4,6]$。

分数矩阵 $S_{ij}=Q_iK_j$：

$$
S=\begin{bmatrix}
1&1&0\\
0&0&0\\
1&1&0
\end{bmatrix}
$$

对每一行做 softmax。第一行 $[1,1,0]$ 减最大值 1 得 $[0,0,-1]$，指数 $[1,1,0.368]$，和 $2.368$，权重 $[0.422,0.422,0.155]$。

第二行全 0，softmax 为 $[1/3,1/3,1/3]$。

第三行与第一行相同。

输出是权重对 $V=[2,4,6]$ 加权：第一行 $0.422\cdot2+0.422\cdot4+0.155\cdot6=3.45$。

这说明：注意力不是“查一个词”，而是把所有 token 的 V 按相关性加权混合。

## 5. MLA 的形状与 KV cache

标准多头注意力每个 token 要缓存 $2$ 份（K 和 V），每层每头 $d_h$ 个数。MLA 把 K/V 压成一个潜向量 $c_t$，缓存的是 $c_t$ 加一个解耦的 RoPE 部分。

V3 配置：61 层，KV 潜向量 512，解耦 RoPE 64。每 token 每层缓存约 $512+64=576$ 个数。用 BF16（2 字节）：

$$
576\times2\times61\approx70{,}272\ \text{字节/ token}
$$

约 70 KB/token。标准 MHA（128 头、每头 128 维、K/V 两份）约为：

$$
2\times128\times128\times2\times61\approx4{,}014{,}080\ \text{字节/ token}
$$

约 4 MB/token。两者差约 57 倍；论文口径的 KV cache 降低约 93.3%、吞吐 5.76 倍，是端到端测量，不等于单 token 字节数的理论比。

## 6. MoE 路由例子

设 1 个共享专家 + 8 个路由专家，每个 token 选 top-2 路由专家。

某 token 对 8 个专家的打分：$[0.1,0.05,0.2,0.15,0.3,0.05,0.1,0.05]$。

top-2 是第 5 个（0.3）和第 3 个（0.2）。归一化后权重：

$$
\frac{0.3}{0.3+0.2}=0.6,\quad \frac{0.2}{0.3+0.2}=0.4
$$

输出 $=0.6\cdot E_5(x)+0.4\cdot E_3(x)+E_{\text{shared}}(x)$。

负载均衡要解决的问题：如果所有 token 都挤向第 3、5 个专家，其余专家收不到梯度，容量浪费。DeepSeekMoE 用无辅助损失的偏置调节与序列级平衡来缓解，不是简单加一个“负载均衡损失”就结束。

## 7. KV cache 字节公式

通用公式：

$$
\text{bytes/token}=2\times L_{\text{layers}}\times H_{\text{kv}}\times d_h\times b
$$

其中 $2$ 表示 K 和 V，$b$ 是每元素字节数（BF16 为 2，FP8 为 1）。

以 1M token、70 KB/token 估算，单序列 KV 约 70 GB；50 并发就是 3.5 TB。这个数字说明为什么长上下文的第一瓶颈是显存，不是算力。

## 8. 自测题

1. $A$ 是 $3\times4$，$B$ 是 $4\times5$，$AB$ 的形状是？（答案：B；解析：中间维度 4 相同，结果取外侧 3 和 5。）
   - A. $3\times4$　B. $3\times5$　C. $4\times5$　D. $5\times3$
2. 头数 $h=8$，$d=512$，每个头维度是多少？（答案：A；解析：$512/8=64$。）
   - A. 64　B. 128　C. 512　D. 8
3. KV cache 公式里为什么有因子 2？（答案：C；解析：K 和 V 各缓存一份。）
   - A. 因为 batch 为 2　B. 因为 FP16 是 2 字节　C. 因为 K 和 V 两份　D. 因为两层残差

## 复习锚点

- 先看形状，再看计算；中间维度必须对上。
- 注意力分数是 $[B,h,L,L]$，不是 $[B,L,L]$。
- softmax 先减最大值，再取指数、归一化。
- KV cache 按“层数 × KV 头数 × 头维度 × 2 × 字节”估。
- MoE 路由是加权组合，负载均衡决定专家是否被充分训练。
