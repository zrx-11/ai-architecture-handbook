# 跨书总览：DeepSeek 架构学习路线

## 推荐学习顺序

| 顺序 | 书 | 为什么在这个位置 | 能力里程碑 |
|---|---|---|---|
| 1 | 基础篇：从零到 Transformer | 你数学和代码接近零基础，先补向量、矩阵、softmax、注意力、Transformer 一层楼，再看 V3 地基 | 能读懂 Transformer 与 V3 架构图，能手算注意力权重 |
| 2 | 论文拆解：R1 / V4 / V4.1 | 有了地基，按“问题—方法—数据—实验—局限”逐篇读原论文 | 能独立拆一篇论文，能说出每篇的结论与边界 |
| 3 | 架构阐释：三代模型的设计逻辑 | 最后做横向比较，把零散组件串成“瓶颈—机制—代价”的判断框架 | 能做架构评审与选型，不被参数和压缩率忽悠 |

## 各书定位（一句话）

- **基础篇**：把论文默认你会的数学和 Transformer 补齐，不追求全面，只讲读 DeepSeek 论文必需的部分。
- **论文拆解**：不替论文吹，也不替论文黑；逐段拆方法、数据和局限，保留原始数字和出处。
- **架构阐释**：不重复论文摘要，重点讲“为什么这样设计、代价是什么、什么负载下不适用”。

## 学习节奏建议

- 每天 2–3 小时，基础篇 5 章约 1 周，论文篇 4 章约 2 周，架构篇 4 章约 1 周。
- 每章先读“一句话核心”和“学习目标”，再做自测；自测低于 80% 就回到对应概念页。
- 每学完一本书，用一次诊断测试（侧边栏“诊断”）抽查，错题会沿依赖链倒推根因。
- 三本书交叉复习：读到 V4 的 CSA 时，回基础篇 ch05 看 KV cache；读到 V4.1 的 CED 时，回论文篇 ch08 看 V4 的混合注意力。

## 总入口

打开 `index.html` 总学习手册，按顺序推进；每本书的进度独立保存，可导出/导入 JSON。
