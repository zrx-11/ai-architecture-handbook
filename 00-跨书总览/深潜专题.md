# 深潜专题：15 套单文件课

这 15 套课都是自包含单文件 HTML，保留交互、公式和折叠推导，不套进统一 manifest 渲染器。它们负责“单点推到底”，主手册负责“广度、依赖顺序、诊断与术语”。两边进度独立保存，学完回主手册做对应章节测验。

合计 15 套、164 节。不要一次全读，卡在哪块补哪块。

## 基础工具

### 1. 数学基础（12 节）

**适合谁**：看到 $\sum$、矩阵、偏导就跳过去的人；或者学过但忘得差不多，需要快速捡回来。

**覆盖**：函数与图像 → 向量与点积 → 矩阵乘与转置 → 导数与偏导 → 链式法则 → 梯度与方向导数 → 概率与条件概率 → 期望、方差、最大似然 → softmax 与交叉熵 → 范数与余弦相似度。每节配可手算的小例子。

**入口**：[打开数学基础](../14-math-deep/index.html)

**建议节奏**：每天 2 节；第 4–6 节必须自己动笔，否则后面反向传播会断。

### 2. Python 与 NumPy（10 节）

**适合谁**：没写过 Python，或者只会 `print`，遇到 NumPy 的 shape、广播、矩阵乘就卡。

**覆盖**：变量与类型 → 列表/字典 → 循环与函数 → 作用域 → NumPy 数组与 shape → 索引/切片 → 广播 → 矩阵乘 → 线性层 → 手写梯度下降。

**入口**：[打开 Python 与 NumPy](../15-python-deep/index.html)

**建议节奏**：边读边在本地跑；第 8–10 节要能独立写出 `(4,3)@(3,2)` 和一次参数更新。

## 机器学习与网络

### 3. 经典机器学习（12 节）

**适合谁**：直接读 DeepSeek 论文，但不知道监督/无监督、过拟合、交叉验证这些词。

**覆盖**：任务与泛化 → 线性回归 → 逻辑回归 → 决策树 → 随机森林/GBDT → KMeans → PCA → 偏差方差与正则 → 交叉验证与数据泄漏 → 类别不平衡 → 模型选型。

**入口**：[打开经典机器学习](../16-classical-ml-deep/index.html)

**建议节奏**：每个算法回答三问：优化什么、用什么数据、失败怎么诊断。

### 4. CNN 与 RNN（10 节）

**适合谁**：只学过全连接，不知道卷积为什么省参数、RNN 为什么会梯度消失。

**覆盖**：卷积与通道 → 池化与感受野 → CNN 结构 → 残差 → RNN → LSTM/GRU → seq2seq → 注意力过渡 → 梯度消失/爆炸。

**入口**：[打开 CNN 与 RNN](../17-cnn-rnn-deep/index.html)

**建议节奏**：第 1–2 节手算输出尺寸；第 6–8 节画一遍门控和 seq2seq 的信息流。

### 5. 反向传播与优化器（10 节）

**适合谁**：会调用框架，但手算两层网络梯度就乱；分不清 SGD、Momentum、Adam 改了什么。

**覆盖**：计算图 → 链式法则 → 多路径梯度相加 → 2-2-1 网络手算 → 矩阵形状 → 梯度消失/爆炸 → SGD/Momentum/RMSProp/Adam → 学习率与初始化 → 5 道自测。

**入口**：[打开反向传播深潜课](../10-backprop-deep/index.html)

**建议节奏**：第 1–4 节必须手算；第 4 节的表能独立复现才算过关。

## Transformer 与 SVM

### 6. Transformer 从零推导（15 节）

**适合谁**：读完基础篇第 3–4 章，觉得“注意力大概懂了，但位置编码、多头、掩码、训练目标还说不清”的人。

**覆盖**：初中数学 → 词嵌入 → 位置编码 → 注意力 → 多头 → 残差/归一化 → 前馈 → 编码器 → 解码器/掩码 → 训练/损失 → 推理/生成 → BERT/GPT → 代码实现。

**入口**：[打开 Transformer 深潜课](../07-transformer-deep/index.html)

**建议节奏**：每天 2–3 节；第 13 节代码实现不要跳。

### 7. SVM 从零推导（16 节）

**适合谁**：读完机器学习第 2、6 章，想把“最大间隔、对偶、KKT、核技巧”真正推明白的人。

**覆盖**：最大间隔 → 硬间隔优化 → 对偶推导 → KKT 与参数恢复 → 手算示例 → 软间隔/hinge → 软间隔对偶 → 核技巧 → 常用核 → 核 SVM 预测 → scikit-learn 实验 → 交叉验证 → 统计学习进阶。

**入口**：[打开 SVM 深潜课](../08-svm-deep/index.html)

**建议节奏**：第 1–5 节慢读，手算示例自己算一遍；第 8–10 节是核技巧核心。

## DeepSeek 架构

### 8. MoE 与 MLA（10 节）

**适合谁**：读 DeepSeek 架构图时，知道有“专家”和“潜在注意力”，但说不清 top-k、共享专家、KV cache 为什么差两个数量级。

**覆盖**：FFN 参数占比 → 路由与 top-k → 负载均衡 → 共享专家 → KV cache 爆账 → MLA 低秩压缩 → MTP/DSA → 全家族对比与选型 → 5 道自测。

**入口**：[打开 MoE 与 MLA](../11-moe-mla-deep/index.html)

**建议节奏**：第 2、5、6 节配 `09-deepseek-family` 第 3–7 章一起读；第 6 节的 KV 账自己按计算器。

### 9. DeepSeek 架构深潜（13 节）

**适合谁**：已经读完 R1/V4/V4.1 论文拆解，想把 MoE、MLA、MTP、DSA、CSA/HCA、mHC/Muon、Engram/DSpark、CED/CSA2 串成一条结构演进线的人。

**覆盖**：家族时间线 → MoE → MLA → MTP → DSA → CSA → HCA → mHC/Muon → Engram/DSpark → V4.1 CED/CSA2 → 选型与成本 → 常见误解。每节都回答“解决什么瓶颈、代价是什么”。

**入口**：[打开 DeepSeek 架构深潜](../19-deepseek-arch-deep/index.html)

**建议节奏**：先读第 1 节时间线，再按“MoE → MLA → DSA → CSA/HCA → V4.1”推进；第 11 节选型表最后读。

## 训练、强化与账本

### 10. 强化学习与 GRPO（10 节）

**适合谁**：知道 R1 用了 RL，但说不清 MDP、策略梯度、PPO、奖励模型、GRPO 的组内优势。

**覆盖**：MDP 与回报 → 策略梯度 → 基线/优势 → PPO → 奖励模型 → KL 与熵 → GRPO 组内归一化 → R1 训练映射 → 奖励设计 → 5 道自测。

**入口**：[打开强化学习与 GRPO](../18-rl-grpo-deep/index.html)

**建议节奏**：第 1–3 节打底；第 6–8 节对照 R1 论文的四个阶段读。

### 11. 训练与推理账本（9 节）

**适合谁**：要判断“这张卡能不能跑 1M 上下文”“训练 7B 要几天”“为什么 decode 比 prefill 慢”，但不想看厂商白皮书。

**覆盖**：参数量与显存 → 训练 FLOPs 6ND → KV cache 公式 → prefill/decode → DP/TP/PP/EP → FP16/FP8/FP4 → 选型 → 5 道自测。

**入口**：[打开训练与推理账本](../13-train-infer-deep/index.html)

**建议节奏**：第 2、3、7 节必须按计算器；算完再去 `09` 第 13 章做 V3/V4.1 的完整 KV 账。

### 12. 概率、损失与评估（10 节）

**适合谁**：数学基础薄弱，看到交叉熵、AUC、precision/recall 就跳过；或者模型评估只看准确率。

**覆盖**：条件概率与贝叶斯 → 最大似然与交叉熵 → 平方损失与高斯噪声 → 偏差/方差 → 正则化 → 混淆矩阵与 P/R/F1 → ROC/AUC/PR → 数据泄漏与交叉验证 → 5 道自测。

**入口**：[打开概率与评估深潜课](../12-probability-eval-deep/index.html)

**建议节奏**：第 2、6 节手算；第 8 节对照自己的项目检查一遍数据泄漏。

## 多模态、评测与上线

### 13. 多模态模型（9 节）

**适合谁**：不知道图像怎么变成 token，分不清 ViT、CLIP、VL、Janus、OCR 各自的角色。

**覆盖**：ViT patch → CLIP 对比学习 → VL 三段式 → DeepSeek-VL/VL2 → Janus 解耦 → OCR/OCR2 → Prover/Math-V2 → 常见误解。含 patch 数与 token 数的手算。

**入口**：[打开多模态模型](../20-multimodal-deep/index.html)

**建议节奏**：第 1–3 节打底；第 5 节 Janus 的解耦动机要能自己复述。

### 14. 评测与安全（9 节）

**适合谁**：要设计评测集、看模型报告，或者被“榜上第一”“裁判打分”骗过。

**覆盖**：任务与指标 → pass@k → LLM-as-judge 偏差 → 幻觉 → 对齐与拒答 → 红队/提示注入 → 数据污染 → 评测集设计。含混淆矩阵与 pass@k 的手算。

**入口**：[打开评测与安全](../21-eval-safety-deep/index.html)

**建议节奏**：第 2、4、6 节重点；第 7 节红队报告要能写出复现步骤。

### 15. 推理部署（9 节）

**适合谁**：模型能跑 demo，但一上线就 OOM、延迟高、吞吐上不去。

**覆盖**：请求生命周期 → KV cache → PagedAttention → continuous batching → TP/PP/EP → FP16/FP8/FP4 → 引擎选型 → SLA 与容量规划。含并发估算。

**入口**：[打开推理部署](../22-serving-deep/index.html)

**建议节奏**：第 2–4 节理解显存与调度；第 7 节拿自己的模型和卡算一遍并发。
