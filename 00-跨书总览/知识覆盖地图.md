# 知识覆盖地图

这张表回答一个具体问题：从“数学和代码接近零基础”到“能拆主流大模型架构、能判断训练/部署成本、能在全球开放模型里做选型”，哪些节点有材料，在哪本分册或哪套深潜课，学完拿什么检查。

覆盖口径：**不是把大学课程全搬进来**，而是覆盖从数学、Python、机器学习、神经网络、深度学习到 Transformer 与主流模型架构所需的最小完整集；DeepSeek R1/V4/V4.1 是案例，全球开放模型是扩展，工程上线另含评测、安全、部署。表里没有的，就是本套材料暂不深讲的缺口，不假装覆盖。

## 三、明确不深讲的缺口

这些不是“忘了”，是本套材料当前边界。看到相关论文时需要另找材料：

- **视频与音频模型**：本套只到图像/文档多模态，不展开视频时序、音频编码、语音合成。
- **Agent 与工具学习**：只在安全章节提到工具滥用，不系统讲规划、记忆、多智能体。
- **可解释性**：不展开注意力可视化、探针、电路分析。
- **分布式训练 kernel 级实现**：讲 TP/PP/EP 的账，不讲具体通信库和 kernel 代码。
- **V4/V4.1 未公开细节**：论文没展开的 kernel、`num_hash_layers` 等，正文标“待确认”，不编造。
- **全球模型的逐 checkpoint 穷举**：全球分册按家族讲，量化/微调/合并版本只在附录索引出现，不逐条拆 config。

## 四、怎么用这张图

1. 先按首页 7 步主线走，不要从矩阵里随便挑。
2. 卡住时在这张图里找对应节点，看“分册”和“深潜课”两列，选一个入口。
3. 学完用“检查点”列自测；过不了就回前置行，不要硬跳。
4. 表里没有的主题，按第三节当作缺口处理，别在本套材料里找不存在的章节。
