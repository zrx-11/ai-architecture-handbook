00课程概览：只补四件事

这门课不从头讲一遍大学数学。它只补读懂神经网络和 DeepSeek 架构必须用到的四块：向量与矩阵、导数与梯度、概率与期望、softmax 与交叉熵。

学完你能做到

  • 看到 $Y=XW+b$ 这种式子，能说出每个符号的形状和含义。
  • 对一个复合函数手写链式法则，不跳步。
  • 说清条件概率、期望、方差在模型里各对应什么。
  • 把一组 logits 算成 softmax 概率，再算交叉熵。

01函数：输入怎么变成输出

函数就是一台机器：给它一个输入，它按固定规则吐出一个输出。写成 $y=f(x)$，$x$ 是输入，$y$ 是输出，$f$ 是规则。

例：$f(x)=2x+1$。输入 3，输出 $2\cdot3+1=7$。输入 -1，输出 $-2+1=-1$。

复合函数

两台机器可以串起来。先算 $f(x)=2x+1$，再把结果喂给 $g(u)=u^2$：

$$g(f(x))=(2x+1)^2$$

输入 3：先 $f(3)=7$，再 $g(7)=49$。复合函数是神经网络的基本形态：一层算完，把输出交给下一层。

线性和非线性

线性函数画出来是直线，形如 $y=kx+b$。非线性函数会弯，比如 $x^2$、$\max(0,x)$、sigmoid。

神经网络如果只堆线性层，堆多少层都等价于一层线性变换。必须夹非线性激活，深度才有意义。
常见错误：把 $f(g(x))$ 和 $f(x)\cdot g(x)$ 混为一谈。前者是串联，后者是相乘，求导规则完全不同。

02向量：一组数怎么比较

向量是一组按顺序排好的数。$[1,2,3]$ 是三维向量，可以看成一个点在三维空间里的坐标，也可以看成一句话或一个词的数值表示。

点积

两个同维向量逐项相乘再相加：

$$\mathbf a\cdot\mathbf b=\sum_i a_i b_i$$

例：$[1,2]\cdot[3,4]=1\cdot3+2\cdot4=11$。

点积衡量“方向有多一致”。同向且长度都为 1 时点积接近 1，垂直时是 0，反向时接近 -1。

模和余弦相似度

$$\|\mathbf a\|=\sqrt{\mathbf a\cdot\mathbf a},\qquad \cos\theta=\frac{\mathbf a\cdot\mathbf b}{\|\mathbf a\|\|\mathbf b\|}$$

例：$[1,2]$ 的模是 $\sqrt{5}\approx2.236$；$[3,4]$ 的模是 5；余弦相似度 $=11/(2.236\cdot5)\approx0.984$。两个方向几乎一致。

Transformer 里的 Q 和 K 做点积，就是在问“这个 token 和那个 token 的方向有多匹配”。点积大，注意力权重就大。

03矩阵：批量做线性变换

矩阵是二维排列的数。$X$ 形状 $B\times d$ 表示 $B$ 个样本、每个样本 $d$ 个数。$W$ 形状 $d\times h$ 表示把 $d$ 维输入变成 $h$ 维输出。

$$Y=XW+b$$

形状怎么对

矩阵乘法要求左边列数等于右边行数。$(B\times d)(d\times h)$ 得到 $B\times h$。$b$ 是长度为 $h$ 的偏置，广播到每一行。

量形状含义
$X$$B\times d$批量输入，一行一个样本
$W$$d\times h$权重，把 $d$ 维映射到 $h$ 维
$b$$h$每个输出维度的偏置
$Y$$B\times h$批量输出

手算一个小例子

$X=\begin{bmatrix}1&2\end{bmatrix}$，$W=\begin{bmatrix}3&4\\5&6\end{bmatrix}$，$b=[0,1]$：

$$XW=[1\cdot3+2\cdot5,\ 1\cdot4+2\cdot6]=[13,16]$$

加偏置得 $[13,17]$。一行输入经过 $2\times2$ 矩阵，变成两个输出。

形状对不上时先检查转置。$XW$ 和 $WX$ 通常不是同一个东西，矩阵乘法不满足交换律。

04导数：变化率

导数回答：输入动一点点，输出动多快。写成 $f'(x)$ 或 $\frac{df}{dx}$。

例：$f(x)=x^2$。在 $x=3$ 处，输入从 3 加到 3.001，输出从 9 变成 $9.006001$，增量约 $0.006$，除以输入增量 $0.001$ 得 6。所以 $f'(3)=6$。

$$\frac{d}{dx}x^2=2x,\qquad \frac{d}{dx}(kx+b)=k$$

常见导数

函数导数用在哪
$x^n$$nx^{n-1}$多项式、损失
$e^x$$e^x$softmax、概率
$\ln x$$1/x$交叉熵、对数似然
$\max(0,x)$0（$x<0$）或 1（$x>0$）ReLU

ReLU 在 0 点不可导，工程上取 0 或 1 都行，不影响训练。

导数为正，说明输入增大时输出增大；导数为负，说明方向相反。梯度下降就是沿着导数为负的方向走一小步，让损失变小。

05链式法则：复合函数怎么求导

复合函数求导，把每一段的导数乘起来。设 $y=g(u)$，$u=f(x)$：

$$\frac{dy}{dx}=\frac{dy}{du}\cdot\frac{du}{dx}$$

例：$y=(2x+1)^2$。令 $u=2x+1$，则 $y=u^2$。

先对 $u$ 求导：$\frac{dy}{du}=2u$。再对 $x$ 求导：$\frac{du}{dx}=2$。乘起来：

$$\frac{dy}{dx}=2u\cdot2=4(2x+1)$$

在 $x=3$ 处，$u=7$，导数 $=4\cdot7=28$。用数值验证：$x$ 从 3 增到 3.001，$y$ 从 $49$ 增到约 $49.028$，增量除以 $0.001$ 约 28。

反向传播就是链式法则的批量版：从损失出发，沿着计算图把局部导数一路乘回去。

06偏导与梯度

函数有多个输入时，对其中一个输入求导、把其他输入当常数，叫偏导。把所有偏导排成向量，叫梯度。

$$f(x,y)=x^2+3y,\qquad \nabla f=\left[\frac{\partial f}{\partial x},\frac{\partial f}{\partial y}\right]=[2x,3]$$

在 $(2,1)$ 处，梯度是 $[4,3]$。它指向函数上升最快的方向；负梯度 $[-4,-3]$ 指向下降最快的方向。

梯度下降

$$\theta_{t+1}=\theta_t-\eta\nabla L(\theta_t)$$

$\theta$ 是参数，$\eta$ 是学习率，$\nabla L$ 是损失对参数的梯度。减号表示往反方向走。

例：$L(w)=w^2$，梯度 $2w$。从 $w=4$ 开始，学习率 0.1：$w$ 更新为 $4-0.1\cdot8=3.2$，再更新为 $3.2-0.1\cdot6.4=2.56$，逐步靠近 0。

梯度只告诉方向，不保证一步到位。学习率太大会越过谷底来回震荡，太小会走得很慢。

07概率与条件概率

概率是 0 到 1 之间的数，表示某个事件发生的可能程度。所有互斥结果的概率加起来等于 1。

条件概率 $P(A\mid B)$ 表示“已知 B 发生，A 发生的概率”：

$$P(A\mid B)=\frac{P(A\cap B)}{P(B)}$$

贝叶斯公式

$$P(A\mid B)=\frac{P(B\mid A)P(A)}{P(B)}$$

例：某种病在人群中患病率 $P(A)=0.01$。检测灵敏度 $P(B\mid A)=0.9$，误报率 $P(B\mid \neg A)=0.05$。检测阳性时真正患病的概率：

$$P(A\mid B)=\frac{0.9\cdot0.01}{0.9\cdot0.01+0.05\cdot0.99}\approx0.154$$

只有 15.4%。因为健康人太多，误报把阳性里的大部分名额占了。这就是“基率”的作用。

语言模型输出的每个 token 概率，也是条件概率：$P(\text{下一个词}\mid\text{前文})$。

08期望、方差与最大似然

期望是长期平均。掷一个六面骰子，点数 $X$ 的期望：

$$E[X]=\sum_x xP(x)=\frac{1+2+3+4+5+6}{6}=3.5$$

方差衡量偏离平均的程度：

$$\mathrm{Var}(X)=E[(X-E[X])^2]$$

骰子的方差：$\frac{1}{6}\sum_{x=1}^6(x-3.5)^2\approx2.92$，标准差约 1.71。

最大似然

给定一堆观测数据，选让这些数据出现概率最大的参数。高斯噪声下，最大化似然等价于最小化平方误差：

$$-\log p(y\mid x)=\frac{(y-\hat y)^2}{2\sigma^2}+\text{常数}$$

所以回归常用 MSE，不是随便选的。分类用交叉熵，也是从最大似然推出来的。

期望不是“最可能出现的值”。骰子期望 3.5，但 3.5 根本不可能掷出来。

09softmax 与交叉熵

模型最后输出一组分数，叫 logits。softmax 把分数变成概率：

$$p_i=\frac{e^{z_i}}{\sum_j e^{z_j}}$$

例：logits $[2,1,0]$。先算指数：$e^2\approx7.389$，$e^1\approx2.718$，$e^0=1$。总和 11.107。概率约 $[0.665,0.245,0.090]$。

交叉熵

真实类别是第 0 类，交叉熵只取正确类别的负对数：

$$L=-\log p_{\text{正确}}=-\log0.665\approx0.408$$

如果模型给正确类别概率 0.9，损失约 0.105；给 0.1，损失约 2.303。越不自信，罚得越重。

softmax 的作用是“放大差异、归一化”；交叉熵的作用是“只奖励正确类别的概率”。两者合起来，梯度形式很干净：$p-y$。
softmax 之前不要自己再加一层归一化。logits 的绝对大小会影响温度，温度越低分布越尖。

10范数与距离

范数是衡量向量“有多大”的函数。最常用两种：

$$\|\mathbf x\|_1=\sum_i|x_i|,\qquad \|\mathbf x\|_2=\sqrt{\sum_i x_i^2}$$

例：$[3,-4]$ 的 L1 范数是 7，L2 范数是 5。

用在哪

场景用的范数效果
L2 正则$\|\mathbf w\|_2^2$把权重压小，限制模型复杂度
L1 正则$\|\mathbf w\|_1$容易把部分权重压到 0，做稀疏
梯度裁剪$\|g\|_2$限制梯度总长度，防爆炸
余弦相似度点积除以 L2 范数只看方向，不看长度

L2 正则的损失形式：$L_{\text{total}}=L_{\text{data}}+\lambda\|\mathbf w\|_2^2$。$\lambda$ 越大，权重被压得越狠。

范数不是“距离”的同义词，但在很多场景可以当距离用。余弦相似度不是范数，它是归一化后的点积。

11常见误解与自测

先排掉四个误解

  • “矩阵乘法就是逐项相乘”：逐项相乘叫 Hadamard 积，矩阵乘法是行与列做点积，规则不同。
  • “导数就是切线斜率，只能看几何”：导数是瞬时变化率，切线斜率只是它的几何解释。
  • “概率为 0 就是不可能”：连续分布里单点概率为 0，但事件仍可能发生；概率是区间上的积分。
  • “softmax 输出一定很自信”：logits 接近时分布很平，温度高时更平。

自测

1. $f(x)=2x+1$，$g(u)=u^2$，$g(f(2))$ 等于多少？

2. $X$ 形状 $B\times d$，$W$ 形状 $d\times h$，$XW$ 的形状是？

3. $y=(2x+1)^2$ 对 $x$ 的导数是？

4. logits $[2,1,0]$ 经过 softmax，第一项概率约是多少？

5. 向量 $[3,-4]$ 的 L2 范数是多少？
