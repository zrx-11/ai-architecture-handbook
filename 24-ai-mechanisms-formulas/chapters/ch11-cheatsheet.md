# 第 11 章：一张纸速查与综合检验

这一章不是新内容，而是把最该记住的 20 个条目压缩成一张纸。考试或做方案时，先看这张纸，再回前面查细节。

## 一句话核心

先记“账”的结构：参数、激活、KV、通信、延迟、成本；再记每个机制改的是哪一项。

## 一张纸：12 个必背公式

| 公式 | 结果 | 常见口径 |
|---|---|---|
| $6ND$ | 训练 FLOPs | 前向 2 + 反向 4；长序列另加注意力 |
| $2N\cdot\text{tokens}$ | 推理 FLOPs | 不含 KV 读写 |
| $2L n_{kv} d_h b\,\text{seq}\,\text{batch}$ | KV cache | 系数 2 是 K 和 V |
| $N\times b/8$ | 权重显存 | 还要加 KV、激活、框架开销 |
| $16$ 字节/参数 | 训练显存 | 权重、梯度、主权重、Adam 两状态 |
| $D\approx20N$ | Chinchilla 配比 | 给定算力最优，不是固定规则 |
| $\mathrm{TTFT}+\mathrm{TPOT}\times L_{out}$ | 总时延 | 两段优化方向相反 |
| $\text{并发}=\text{吞吐}\times\text{时延}$ | Little 定律 | 容量规划基本式 |
| $2n_hd_h/(d_c+d_r)$ | MLA 压缩比 | 省带宽，多一次投影 |
| $N\times b/8$ | 量化权重 | 4bit 不是简单除以 4 |
| $1-(1-p)^n$ | 拒绝采样通过率 | 成本随 n 线性涨 |
| $1/\sqrt n$ | 奖励模型方差 | 数据翻倍只降约 30% 误差 |

## 一张纸：15 个必认机制

1. BPE：词表决定计费与上下文。
2. RMSNorm：深层网络尺度稳定器。
3. RoPE：相对位置，超出训练长度要缩放。
4. GQA：多个 Q 头共享 K/V，省 KV 显存。
5. MLA：低秩潜向量压 KV，省带宽花算力。
6. MoE：总参数换容量，激活参数换成本。
7. Mamba/KDA：固定状态换线性成本，长程召回是短板。
8. Attention Sink：KV 驱逐必须保留开头 token。
9. 梯度检查点：省激活，训练变慢。
10. ZeRO/FSDP：切优化器状态，先切最占地方的那份。
11. RLVR：可验证任务用验证器给奖励，不需要奖励模型。
12. DPO：偏好数据直接优化，省掉在线采样。
13. PagedAttention：KV 分页，碎片变少、吞吐变高。
14. PD 分离：prefill 算力密集，decode 带宽密集。
15. 提示注入：Agent 读到的数据里藏指令，攻击“数据/指令不分”。

## 综合检验

### 题 1：给一个 70B 模型做 128K 推理预算

要求：算权重显存（bf16 与 int4 各一次）、单请求 KV、20 并发 KV，判断单卡 80GB 能否放下。必须写出每一步单位。

### 题 2：MoE 账本

要求：总参数 671B、top-8/256、共享专家 1 个，估激活参数；解释为什么实际报的激活参数可能高于 $(k/N)\times$ 总参数。

### 题 3：选后训练路线

场景：数学题有标准答案；客服回复没有唯一答案。分别选 SFT、RLVR、DPO、RLHF 中的哪条，为什么？说出数据需求与失败模式。

### 题 4：推理优化顺序

场景：TTFT 2 秒、TPOT 80ms、P99 超 SLA。给出三步排查顺序，并说明哪一步该先做量化、哪一步该先做 PD 分离。

### 题 5：Agent 安全评审

要求：为一个能读网页、发邮件的 Agent 写 5 条护栏；至少覆盖提示注入、工具权限、出站内容、审计与人工确认。

## 覆盖边界

- 本文覆盖 114 个机制与 104 个公式的索引级解释；每个条目给“是什么、代价、回哪章”，不替代原始长文与论文。
- 2026 年文章里涉及未完全公开的型号（Kimi K3、DeepSeek V4 等）的细节，标“文章口径”；以官方 config/技术报告为准。
- 机制编号是索引，不是学习顺序；真正的顺序仍按主手册 7 步走。

## 复习锚点

- 先账本，后机制；先单位，后数字。
- 生成、训练、推理、对齐，四本账不要混。
- 任何“省”都要问：省的是显存、带宽、算力还是标注？
