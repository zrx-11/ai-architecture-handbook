# 第 6 章：生成、应用与安全（87–114）

这一组把视线从“模型内部”移到“模型对外”：图像与视频怎么生成，RAG 与 Agent 怎么搭，安全与隐私怎么防。

## 一句话核心

生成模型换的是数据分布，应用架构换的是上下文与工具，安全换的是攻击面。三者不要混成一个“模型能力”问题。

## 学习目标

- 能区分扩散、GAN、流匹配、VAE、DiT 各自解决什么。
- 能画出 RAG、Agent、函数调用、记忆系统的最小链路。
- 能说出越狱、提示注入、后门、对抗样本各自攻击哪一层。

## 机制表

| # | 机制 | 一句话 | 代价或边界 |
|---|---|---|---|
| 87 | 扩散 | 前向逐步加噪，反向训练网络预测噪声并去噪 | 训练稳；采样要几十步，成本高 |
| 88 | GAN | 生成器造假，判别器辨真，交替训练 | 理论优雅；实践易崩，模大规模生成已退场 |
| 89 | 世界模型 | 先训“预测下一帧”，再在模型内部训练智能体 | 省真实环境成本；梦与现实有偏差 |
| 90 | 流匹配 | 直接学噪声到数据的直线速度场 | 采样步数更少；Stable Diffusion 3/Flux 后主流 |
| 91 | VAE | 编码器压成概率分布，解码器重建；损失含 KL | 扩散的隐空间地基；KL 权重是取舍 |
| 92 | DiT | 把 U-Net 换成 Transformer，图像 patch 与文本条件进注意力 | 数据量大时归纳偏置反成限制；与语言模型共用骨架 |
| 93 | 无分类器引导 CFG | 有条件与无条件噪声预测的差，按 s 放大 | s 越大越贴提示，太大过饱和、多样性塌陷 |
| 94 | 自回归图像生成 | 图像压成离散 token，像语言模型一样逐个预测 | 与文本共用模型与采样；token 多、生成慢 |
| 95 | 视频时空注意力 | 先空间后时间分开算，避免三维全注意力 | 复杂度低一个数量级；长程动作容易断 |
| 96 | 嵌入与对比学习 | 正样本靠近、随机配对分开，大批量负样本近似全库比较 | RAG 召回质量八成取决于这一步 |
| 97 | RAG 链路 | 切块 → 嵌入 → 向量库 → 召回 → 重排 → 拼 prompt | 任何一环掉链子都会胡编 |
| 98 | Agent 循环 | 模型发工具调用 → 运行时执行 → 结果塞回上下文 | 工程难点是错误处理、缺参、无限循环 |
| 99 | Harness 六部件 | 工具表、循环器、上下文管理、状态存储、守卫、追踪 | 模型只负责想，其余六件由 harness 承担 |
| 100 | 函数调用 | 工具写成 schema，模型输出结构化调用，系统执行 | 工具描述质量直接决定调用成功率 |
| 101 | 记忆系统 | 写入、检索、遗忘三动作；写入由模型判断 | 写错会被反复检索，越用越像真的 |
| 102 | 多智能体协作 | 流水线、辩论、投票三种拓扑 | 同源模型辩论会收敛到同一套偏见 |
| 103 | 护栏与可观测性 | 入侧分类器加规则，出侧隐私与策略模型，trace 记全链路 | 没记工具参数与规则 id，出事无法定位 |
| 104 | 混合检索 | 向量召回语义，BM25 召回精确词，再融合重排 | 纯向量召不回型号编号；纯关键词不懂同义 |
| 105 | 越狱 | 对抗后缀、角色扮演、编码绕过，让模型说它不该说的 | 攻击的是安全训练与指令跟随的优先级 |
| 106 | 提示注入 | 把指令藏进网页、邮件、PDF、工具返回值 | 攻击“模型分不清数据与指令”的结构缺陷 |
| 107 | 后门攻击 | 训练语料埋触发器，特定词出现才切到攻击行为 | 隐蔽性来自触发器，不来自样本量 |
| 108 | 对抗样本 | 沿损失上升方向加不可见扰动，让模型判错 | 对抗训练有效但昂贵，新攻击仍能找到方向 |
| 109 | 成员推断 | 判断某条数据是否在训练集：loss 更低、置信度更高 | 隐私泄露最直接的证据形式 |
| 110 | 数字水印 | 采样时按密钥给绿组 token 加偏置，检测绿组占比 | 改写、翻译、截断都可能洗掉 |
| 111 | 校准 | 用温度缩放让置信度与真实正确率对齐 | 不改变排序，只改变“说得多肯定” |
| 112 | LLM 裁判偏差 | 偏爱长答案、偏爱同源措辞、对选项顺序敏感 | 不校准的裁判测的是自己的口味 |
| 113 | 差分隐私 DP-SGD | 梯度裁剪 + 高斯噪声，按 ε 记账 | 噪声越大越私密，模型越笨 |
| 114 | 联邦学习 FedAvg | 各端本地训练，只传更新，中心按样本量加权平均 | 数据不出门，梯度仍可能泄露；LLM 预训练基本没落地 |

## 三条链路

1. 生成：VAE/DiT/扩散或流匹配 → 采样 → 视频时空注意力。
2. 应用：切块/嵌入 → 召回/重排 → Agent 循环 → 记忆与护栏。
3. 安全：入侧规则 → 模型策略 → 出侧隐私 → trace 与红队。

## 常见误解

- “RAG 能解决幻觉。”召回错了，RAG 只会更自信地胡编。
- “Agent 是一个更大的模型。”Agent 的主体是 harness，模型只是决策器。
- “提示注入只影响一句话。”Agent 能执行工具后，它会升级成替用户执行动作。

## 自测

1. 扩散、流匹配、GAN 的训练稳定性为什么不同？
2. RAG 链路里哪一步最容易被忽略，却最影响答案？
3. 越狱与提示注入的攻击对象有什么不同？

## 复习锚点

- 生成看采样成本，应用看链路，安查看攻击面。
- RAG 的瓶颈常在切块与重排，不在生成。
- Agent 的难点在错误处理与上下文管理。
